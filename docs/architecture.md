## Dependency Flow

The codebase follows a hub-and-spoke topology. The **CLI** module is the primary entry point and the only module with outbound runtime dependencies — it imports from **lib-provider**, which in turn fans out to three provider adapters (Claude Code, OpenCode, Codex). All other modules are standalone: skill modules are self-contained markdown instruction sets consumed directly by Claude with no runtime import relationships; library modules (lib-repomap, lib-session, lib-source-manifest, lib-issues) are invoked by skill companion scripts or the CLI but do not import each other. The test module provides shared helpers but is not imported by production code.
