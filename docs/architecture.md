## Dependency Flow

The adev-plugin codebase is composed of standalone modules with minimal inter-module JavaScript imports. The CLI module is the primary runtime entry point, installing skills and hooks into the user's Claude Code environment. Hooks are independent bash scripts that execute as Claude Code lifecycle events. All skill modules are self-contained markdown instruction sets consumed directly by Claude — they have no runtime import relationships with each other. The repomap (under lib/) parses TypeScript source files and produces the JSON artifacts consumed by `/adev-document` and `/adev-validate`; it is the only module with internal file-to-file dependencies, which are confined to the test fixtures.
