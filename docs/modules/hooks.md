# Module: Hooks

> Generated by /adev:document on 2026-04-02.

## Purpose

Bash hooks that integrate with Claude Code's hook protocol. Includes constitution linter (validates agent output against project principles), merge guard (blocks merges to protected branches), session start injector (loads context on session start), and sync trigger (runs /adev:sync on relevant file changes). Hooks read JSON from stdin + environment variables, exit 0 (allow) or 2 (block), and output JSON to stdout.
