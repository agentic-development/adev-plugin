# Module: Hooks

> Generated by /adev:document on 2026-04-02. Updated 2026-04-06.

## Purpose

Bash hooks that integrate with Claude Code's hook protocol. Includes constitution linter (validates agent output against project principles), merge guard (blocks merges to protected branches), session start injector (loads context and execution state resume on session start), session capture (JSONL tool-use logging), issue reminder (periodic issue surfacing with idle nudge), context preflight (warns on source edits without context reads), context read tracker (flags context reads), and sync trigger (runs /adev:sync on relevant file changes). Hooks read JSON from stdin + environment variables, exit 0 (allow) or 2 (block), and output JSON to stdout.

## Key Exports

No JavaScript exports — hooks are standalone scripts registered via `hooks/hooks.json`.

| Hook | Trigger | Location | Description |
|------|---------|----------|-------------|
| `constitution-linter` | PreToolUse (Edit) | `hooks/constitution-linter.sh` | Validates agent output against constitution |
| `merge-guard` | PreToolUse (Bash) | `hooks/merge-guard.sh` | Blocks merges to protected branches |
| `context-preflight` | PreToolUse (Edit) | `hooks/context-preflight.sh` | Warns on source edits without context reads |
| `context-read-tracker` | PostToolUse (Read) | `hooks/context-read-tracker.sh` | Tracks context reads for preflight check |
| `sync-trigger` | PostToolUse (Edit) | `hooks/sync-trigger.sh` | Triggers /adev:sync on constitution changes |
| `session-start` | SessionStart | `hooks/session-start.sh` | Injects using-adev skill + execution state resume block |
| `session-capture` | PostToolUse (.*) | `hooks/session-capture.sh` | Appends JSONL tracking entries to `.session-tracking.jsonl` |
| `issue-reminder` | PostToolUse (.*) | `hooks/issue-reminder.sh` + `.mjs` | Surfaces active issues every N tool calls; idle nudge when no work in progress |
