## Testing: Your Judgment

This project's `implementation_mode` is `agent-default`. adev imposes no test requirement and no test order on this task.

- Decide whether the task needs new or changed tests. Add them where they protect behavior that matters, and skip them where they would only restate the implementation.
- Run the tests relevant to what you changed before reporting, so you do not hand back a red suite.
- Say in your report which tests you added or changed, or why you added none.
