# Generate Developer Documentation

Produce documentation in `docs/` from `.context-index/` artifacts.

## Arguments

- No arguments: generate all documentation
- `--module <slug>`: regenerate only `docs/modules/<slug>.md`
- `--check`: compute diff without writing
- `--force`: regenerate all sections unconditionally

## Precondition Checks

1. `.context-index/hygiene/dependency-graph.json` exists
2. `.context-index/hygiene/symbol-ranks.json` exists
3. `.context-index/manifest.yaml` exists
4. If `docs/` doesn't exist, create it

Stop with error if missing.

## Marker Protocol

Two-zone layout:

```
[generated content]

<!-- adev:generated -->

<!-- adev:human -->

[human content, never overwritten]
```

| Condition | Action |
|-----------|--------|
| Both markers present | Preserve after `<!-- adev:human -->` |
| Only `<!-- adev:human -->` | Do NOT overwrite |
| Only `<!-- adev:generated -->` | Regenerate entire |
| Neither marker | Write fresh with markers |

## Step 1: Generate docs/architecture.md

### Load Inputs

| File | Required | Purpose |
|------|----------|---------|
| `dependency-graph.json` | Yes | Module edges |
| `symbol-ranks.json` | Yes | Exported symbols |
| `manifest.yaml` | Yes | Module list |
| `constitution.md` | Optional | Principles |
| `platform-context.yaml` | Optional | Environment |

### Build Module Map

Table: Module, Purpose, Key Exports, Inbound, Outbound

### Dependency Flow

Prose: core modules, leaf consumers, middleware

### Entry Points

Files with zero inbound edges.

### ADR Links

Find ADRs, extract status, produce links.

### Assemble

```markdown
# Architecture

> Generated by $adev-document on <timestamp>

## Module Map
<table>

## Dependency Flow
<paragraph>

## Entry Points
<list>

## ADRs
<links>

<!-- adev:generated -->

<!-- adev:human -->
```

## Step 2: Generate docs/modules/<slug>.md

For each module:

**Purpose:** From charter or manifest

**Key Exports:** Top 10 symbols from symbol-ranks

**Dependencies:** Inbound/outbound from graph

**Related Specs:** Glob specs under module

```markdown
# Module: <name>

> Generated by $adev-document

## Purpose
<Business Intent>

## Key Exports
| Symbol | Kind | Location | Score |

## Dependencies
**Inbound:** Module A, B
**Outbound:** Module C

## Related Specs
- [charter.md](path)

<!-- adev:generated -->

<!-- adev:human -->
```

## Step 3: Generate docs/GENERATED.md

Manifest of generated files:

```markdown
# Generated Documentation Manifest

| File | Sections | Last Commit | Last Run |
|------|----------|-------------|----------|
| docs/architecture.md | Module Map, Dependency Flow | abc1234 | 2026-03-23 |
```

## After Generation

```
Documentation generated:

  docs/architecture.md — module map, dependency flow, entry points
  docs/modules/<slug>.md — per-module purpose, exports, dependencies
  docs/GENERATED.md — manifest

Run $adev-document --check to preview changes.
```
