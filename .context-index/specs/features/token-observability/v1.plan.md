# Implementation Plan: Token Observability v1

> **Methodology:** adev
> **Charter:** .context-index/specs/features/token-observability/charter.md
> **Specs:** .context-index/specs/features/token-observability/scenario-registry.md, .context-index/specs/features/token-observability/phase-token-capture.md, .context-index/specs/features/token-observability/run-orchestration.md, .context-index/specs/features/token-observability/scenario-reporting.md
> **Review:** PASS_WITH_NOTES (2026-03-25)
> **Platform:** Node.js, JavaScript (ESM), npm, node:test

**Goal:** Build a dependency-free lifecycle token observability eval harness that measures token usage across full adev workflow scenarios, including retries and subagent-heavy review phases.

**Architecture:** The implementation lives entirely under `tests/evals/lifecycle-tokens/` plus one npm script entry in `package.json`. A validated scenario registry drives a serial runner. The runner executes scenario phases through a wrapper contract, records normalized raw token events, enforces bounded execution, then emits one Markdown report per run plus a rollup report for the invocation.
