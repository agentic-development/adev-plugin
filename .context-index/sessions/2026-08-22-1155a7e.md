## Intent

feat(review): diff-scope reviewer dispatch and context on non-first review cycles

Adds lib/governance/diff-scope.mjs (extractChangedSections,
expandWithCrossReferences -- pure text functions) and `adev governance
diff-scope --spec <path>` (lib/cli/governance.mjs), which reads the
lifecycle log to decide whether a review cycle can scope to just the
changed + cross-referenced sections: scoped:false on a spec's first
review (always full-context, per BEH-8) or when the prior committed
text can't be read (git-unavailable, fails OPEN to full context --
diff-scoping is a cost optimization, never a correctness gate).

skills/review-specs/SKILL.md Step 4 calls it before the shouldDispatch
loop and uses the scoped content as specContent (affects only
triggered reviewers' keyword scoring -- dispatch: always reviewers are
unaffected) and as the text each dispatched reviewer's context is
restricted to.

Also corrects three "three specialists" mentions to describe the
dispatched set as whatever `adev governance reviewers` resolves for
the project, closing the base spec's stale structural-architect/
security-reviewer/consistency-analyzer trio reference (this project's
registry has since retargeted to referent-integrity/wiring-reviewer/
boundary-reviewer/consistency-analyzer/termination-reviewer).
