## Intent

fix(lifecycle-artifacts): specify emits lifecycle events for all 5 modes

Resolves issue-511 (under epic-74 / adev-compiler-discipline milestone).

PR #131 (issue-508) added --verdict PASS to /adev:specify's Standard Mode
completion emission, but Extract, Refactor, From-Diff, and Cross-Cutting
modes were not addressed. Those four modes emit NO lifecycle events at
all — specs authored via them have empty lifecycle-state/<slug>.jsonl
files, and /adev:review-specs blocks in strict mode with
"step 'review' requires prior step 'specify' to be completed".

Fix: factor the entry/exit emissions into a new "Shared: Lifecycle
Events" section, then add a Step 0 (entry-event reference) and a Summary-
step exit-event reference to each of the four non-Standard modes.

Section added:
- "Shared: Lifecycle Events" — documents the entry/exit contract,
  including the cross-cutting spec-path special case.

Per-mode references added (8 edits, 2 per mode):
- Extract: Step 0 entry + Step 5 Summary exit.
- Refactor: Step 0 entry + Step 8 Summary exit.
- From-Diff: Step 0 entry + Step 5 Summary exit.
- Cross-Cutting: Step 0 entry + Step 6 Summary exit (notes the
  cross-cutting spec path).

Standard Mode is unchanged here — its explicit Step 0/Step 6 emissions
landed in PR #131 (issue-508) and serve as the canonical example the
Shared section references.

Failure paths emit --status failed separately and do not reach the
Summary step. Success-path PASS verdict is the right contract.

No code changes — markdown-only edits to one SKILL.md file.
