Follow-up to the rev-2 JSON sidecar migration (commits 4d389a1 +
3a32106). The detector in lib/plan-immutability.mjs now flags 20
legacy plan files that carry inline **Routing:** blocks but have no
sibling .routing.json — the same shape issue-526 was filed against,

un-migrated plans (detector flags them; migration is a follow-up)"),
so it gets its own tracker.

with the existing agent-reliable-state-artifacts capability
"Cursor-provider 5-plan migration" (1 of the 5 cursor-provider
plans shows in the flagged list, suggesting the existing
lib/migrate-plan-routing.mjs is the natural foundation), and
specifies idempotency + exempt_commits stamping for the migration
tool.
