## Intent

fix(tests): run the bucket the runner announces — --evals ran the default set

scripts/run-tests.mjs computed `selected` from --evals/--all, printed
"run-tests: running 20 of 454 files", and then spawned `...files` — the
DEFAULT bucket. So `npm run test:evals` executed all 428 default files and
reported green having never run a single eval harness. `npm run test:all`
was equally hollow.

This is the same silent-shrink failure as the sh-glob bug that motivated this
runner, one layer up, and it defeats the issue-612 decision directly: that
decision's whole claim is that infra-dependent suites are not hidden, merely
opt-in and "reachable by an explicit script". The script was not reaching them.

Found while adding tests/evals/beads-live/ and noticing `npm run test:evals`
reported the same 5552 tests as `npm test`.

Consequence, stated plainly: the eval bucket has 26 failing tests that were
masked by this. They are pre-existing and are the ones issue-612 catalogued —
integration-sandbox needs PostgreSQL on 5433, comparison needs an API key,
skill-compression needs local session JSONL. None are regressions from this
branch, and the default gate is green at 5552/5552. They are now visible,
which is the point.

The regression tests assert both halves: that the spawn uses `selected`, and
that the eval bucket is a distinct non-empty set — the second matters because
if the buckets were equal the first would pass while --evals still ran the
default set.
