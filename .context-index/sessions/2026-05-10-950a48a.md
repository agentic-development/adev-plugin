## Intent

refactor(domain-profiles): replace overlay merging with full domain templates

Replace H2-section-matching overlay merge system with complete domain
templates. Each domain now ships charter-template.md and spec-template.md
(full templates) instead of charter-overlay.md and spec-overlay.md
(fragments). This eliminates the competing sources of truth where skills
had hardcoded section names that conflicted with dynamically merged overlays.

Changes:
- Generate full templates from base + overlay for all 3 bundled domains
- Delete all 6 overlay fragment files
- Rename OVERLAY_TYPES: charter-overlay -> charter-template, spec-overlay -> spec-template
- Add DEPRECATED_OVERLAY_TYPES map with deprecation warning for old names
- Remove mergeTemplateOverlay() import from integration tests
- Update brainstorm/specify skills to load templates directly via loadOverlay()
- Remove hardcoded section names from skill prose
- Update charter entity TemplateOverlay -> DomainTemplate
- Update all 3 sibling specs to rev 6 with new type/file references
- Bump charter to rev 5
