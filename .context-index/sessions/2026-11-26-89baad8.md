## Intent

feat(implementation): add adev implement lite-report

lite-report counts the tasks of the most recent implement run whose latest
final-pass review_depth_resolved event is lite, so /adev:validate can say
which tasks shipped without per-task review. It reads raw lifecycle
events after the latest implement started event, folds per plan and task,
and prints {count, task_ids, since} with --json or a single advisory line
(nothing at count 0). A task the tripwire escalated is not counted.

Review depth: quick synthesized review by operator override. Final-pass
depth not recorded: the task ran in a parallel worktree.
