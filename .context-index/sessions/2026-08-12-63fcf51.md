## Intent

feat(pr-review-brief): spec review-packet-template

Covers the charter's remaining must-have capability: the review packet
field set. Authored as kind: artifact, not behavioral — the deliverable is
a static .github/pull_request_template.md that GitHub reads verbatim, so
the contract is a structural shape, not a runtime behavior.

Four author-written H2 sections with contractual heading text (What / Risk
areas and trust boundaries touched / Verified line by line / What I cannot
explain), each carrying an HTML-comment prompt so an unfilled section reads
as unfilled rather than as absent.

The "What I cannot explain" section is non-omittable by test. Same design
principle as pr-body-composition's UNKNOWN rows: an empty answer is a claim
the author made, a deleted section is silence, and the two must not look
alike.

The file ends with an empty <!-- adev:pr-brief --> marker pair. That
reserves the insertion point for `adev pr body` output and pins the
authorship boundary the charter puts in scope — author content above,
generated content below, contiguous, never interleaved. Requiring the
closing marker to be the last non-blank line means a naive
replace-to-end-of-block delivery in cicd cannot swallow author text.

Path ownership checked before claiming .github/pull_request_template.md:
cicd scopes itself to .github/workflows/ and copilot-provider to
.github/skills/. Neither claims it.

Two findings recorded rather than left for review to rediscover:

- The constitution mandates kebab-case filenames; pull_request_template.md
  is snake_case because GitHub resolves that exact path. Documented as a
  confined exception.
- `gh pr create` picks up the template only when neither --body nor --fill
  is passed, so skills/validate:566 and skills/implement:649 must name the
  template explicitly or agent-opened PRs carry no packet at all.

No bundled copy: templates/ has no .github/ scaffolding and /adev:init
writes only .context-index/, so shipping one is an init-charter scope
decision. Deferred with that reason stated.

Charter Capability Map: "Review packet field set" -> specified. Bound to
issue-613 on the board.
