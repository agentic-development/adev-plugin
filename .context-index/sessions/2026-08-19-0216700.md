providers/cursor/adapter.mjs parsed the frontmatter `name:` with
/^name:\s*(\S+)\s*$/. `\S+` is a fine YAML scalar grammar and a wrong
filesystem-path grammar — it admits `/` and `..`, so a skill declaring
`name: adev:../../x` produced a sanitizedName that flowed unchecked into
join(targetSkillsDir, ...) and then cpSync + writeFileSync. copilot
realpath-contains every destination; cursor had no equivalent anywhere.

The flaw predates this work. The recursive references/ copy widened what
flows through it, which is why it is fixed here rather than deferred.

  - published skill names must be a single path segment; a traversing name
    is REFUSED rather than re-sanitized, because a name needing path-stripping
    is malformed and rewriting it would publish under a name the skill does
    not declare
  - the resolved destination is containment-checked before any write

the allowlist. One of its cases was wrong on first write — `adev-.` is a legal
POSIX directory name, not a traversal — and the test was corrected rather than
the guard loosened to satisfy it.
