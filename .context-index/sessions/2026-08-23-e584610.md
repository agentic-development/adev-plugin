## Intent

fix(strategic-planning): fix convergence eval's null verdict/cost bugs

Two bugs found live while running Task 12's --baseline-ref A/B eval:

1. TERMINAL_VERDICTS omitted plain BLOCK. The unamended (baseline) loop's
   sidecar+fail-loud path on first BLOCK never rewrites step_completed to
   one of the loop-convergence verdicts, so every baseline-arm trial's
   true terminal state is a bare BLOCK -- summarizeTrial() silently read
   this as null. Also added the legitimate EXTERNAL_REMEDY verdict, which
   was documented in a comment but missing from the actual array.

2. SANDBOX_PROJECT_KEY only replaced `/` with `-`, but Claude Code's real
   session-directory hashing replaces every non-alphanumeric character.
   This repo's own worktree path contains a literal `.claude` segment
   whose dot the naive replacement missed, so SESSIONS_DIR pointed at a
   directory that doesn't exist and waitForSessionStats() never found the
   real session file -- cost/tokens read as null/$0.000 on every trial.
   Verified the fix against the actual directory Claude Code created for
   this checkout, not assumed.
