## Intent

feat(agent-reliable-state-artifacts): orphan-lock recovery in _acquireLock

Adds stat → age-check → unlink → retry-once recovery branch to
JsonAdapter._acquireLock. On EEXIST, stats the lock file; if mtime is
older than cas_lock_stale_seconds (default 30s), treats it as orphaned,
unlinks, and retries openSync exactly once. Emits a single stderr
warning per process lifetime (per adapter instance) on successful
recovery.

The naturally-released race (ENOENT on stat) retries once and falls
through to STALE_BOARD_WRITE_RETRY if the retry hits EEXIST — does
NOT re-enter orphan recovery (review note SA-1).

unlink failure surfaces BOARD_ORPHAN_LOCK_UNLINK_FAILED with the
original error on err.cause. Warning and error messages use the
literal string 'tasks.json.lock' and never interpolate lockPath
(review note SEC-1).

Adds statSync to the node:fs import. Adds
_orphanRecoveryWarningEmitted instance flag for one-time-per-process
warning suppression (Behavior 3).
