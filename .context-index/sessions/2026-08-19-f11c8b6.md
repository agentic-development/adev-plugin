/adev:hygiene and /adev:retro. This commit is the reconciliation.

tests caught it.

no guard for broken conditional-loading pointers, none for unreferenced

companion parity, and no measured token figure -- every number in the spec is
bytes, or bytes over 4.08, which the stored heuristic warns overstates savings
by 2-2.5x.

filter-branch, and the feature is bound to the board as
adev-plugin-skill-body-progressive-disclosure-p6l6, related to the four issues
it implements.
