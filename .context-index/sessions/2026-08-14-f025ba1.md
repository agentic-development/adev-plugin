## Intent

docs(governance): revise to rev 2 — address all five review blockers

SA-1: the upgrade window is now specified. Removing the runtime overlay ships
in the plugin while materialize runs in the project, so a project between the
two had an empty effective set and would have run zero reviewers while still
reporting a verdict. Loaders now fail closed with REGISTRY_NOT_MATERIALIZED
rather than degrading silently. Auto-materialize-on-read was rejected — a
silent config write during an unrelated command is the opposite of what this
spec is for.

SA-2: Check 9's populated case is now specified, including the boundary the
reviewer asked for — it reads recorded gate outcomes from the lifecycle log,
does not execute gates, and does not evaluate workflow preconditions, which
ADR-0010 routes to requireGate.

SEC-1/2/3 are folded into Step 3 as prerequisites, since they are live defects
in shipped code that this spec depends on. Both are now also tracked
independently as adev-plugin-xg1f.1 and xg1f.2. SEC-2 was reproduced during
review: an extension-supplied target of '../../ESCAPED.yaml' wrote outside
.context-index/governance/ with no error, while two sibling installers in the
same file already do the containment check.

Also: SEC-4 adds a disabled-check audit to hygiene, SA-3 restates the
boundaries-to-diagnostics exclusion against ADR-0010's actual precondition
(a runner template inside the diagnostic registry, not regex evaluation as
such), SA-4 corrects two step cross-references that disagreed about the
ordering argument, SA-5 corrects the gate baseline, SA-6 clarifies that
PASS becomes SKIP so a regression test cannot pin the wrong verdict, and
CON-1 fixes a spelling.
