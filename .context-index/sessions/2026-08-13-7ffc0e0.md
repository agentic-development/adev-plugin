## Intent

feat(gates): ship live fast and integration tiers in gates-template

Every gate in the template was commented out, so a fresh scaffold declared no
tiers at all and the shipped tier engine was unreachable by default. Uncomment
the `test` (fast) and `integration-test` (integration) entries as live YAML,
unchanged in field set and ordering, each carrying `command: ""` — the unwired
sentinel. mergeGates drops a falsy command with a named INVALID_GATE warning,
so both tiers are declared in every scaffold and an unseeded init produces an
actionable message instead of silence. The sentinel is "" and not []: an empty
array is truthy AND an array, so it passes both validateGate guards and would
reach the executor with nothing to run.

Convert the schema header and every remaining commented example to argv form
and state that a string command is rejected at load by lib/domains/merge-gates
with INVALID_GATE. transitions stays live and empty on purpose — binding
implement-to-validate to a gate whose command is still the sentinel would make
a fresh scaffold fail closed under hygiene Pass 8.

The template test asserted with content.includes(), which a fully commented-out
file satisfies. It now parses the template with parseYaml and asserts over the
document, plus a raw-text sweep rejecting any non-empty quoted command value.
