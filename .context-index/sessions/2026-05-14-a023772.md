feat(cli-driver-surface): amend diagnostic-registry spec to rev 2 + ADR-0009

Resolves four behavioral-duplication concerns surfaced by a consistency
pass over the cli-driver-surface charter, then re-reviewed twice to PASS.

  diagnostic-registry.spec.md (rev 1 → rev 2)
    15-clause rev 2 amendment block tracks every change.

      (1) Drop adev/lifecycle-prerequisite-met Tier-1 producer + the
          governance/diagnostics.yaml::prerequisites: map. Lifecycle
          step-order is enforced by requireGate in lib/lifecycle-state.mjs;
          STEP_ORDER (lib/lifecycle-state.mjs:859) remains the single
          source of truth. Detecting manual JSONL edits is deferred to
          a future Tier-2 forensic producer. Producer count: 4 → 3.
      (2) Tighten adev/event-schema-valid to closed-discriminator /
          open-per-type-shape. Six known event types form a closed enum;
          per-type schemas validate required fields only, permit extras.
          StateProjection.unknownEvents[] is deprecated.
      (3) Extract shared lib/spec-status.mjs (exports SPEC_STATUSES +
          assertLegalStatus). status-enum-legal producer imports from
          it. Lib-side writers migrated in the same implementation.
      (4) Strengthen runner-path containment (Behavior 2 Steps A–D):
          .. rejection on raw input, prefix-required (plugin: / project:),
          fs.realpathSync resolution, per-root containment, cross-root
          confused-deputy rejection. Pure string-prefix containment is
          explicitly forbidden. AC requires 6 test cases.
      (5) SCHEMA_INVALID casing propagated across Error Cases + AC.
      (6) Narrow runner allowlist to lib/diagnostics/ (plugin) and
          .context-index/diagnostics/ (project). Bare relative,
          absolute, node_modules/, lib/ (non-diagnostics) all rejected.
      (7) Hard timeout: Promise.race([runner.run(ctx), timeout(500)])
          emits adev/diagnostic-timeout (error) and abandons the
          runner's promise. 200 ms soft observability via
          adev/diagnostic-slow unchanged.
      (8) Closed-discriminator enforcement is mode-dependent:
          normaliseEventInPlace stays permissive; strict/tag/off behavior
          governed by lifecycle.event_diagnostics manifest knob.
      (9) Message redaction contract: project: / plugin: / ~/ rewriting,
          <external-path-redacted> for everything else, stack traces
          never surfaced in errors[].message.
     (10) Migration scope tightened to 2 grep-confirmed files
          (lib/meta-tools.mjs, lib/reality-check.mjs) with re-grep
          instruction at implementation time.
     (11) ACs added for templates/diagnostics-template.yaml and
          lib/diagnostics/event-schemas.mjs.
     (12) Per-type schema authority chain documented:
          agent-reliable-state-artifacts/lifecycle-event-log.spec.md
          is canonical; event-schemas.mjs is a mechanical mirror.
     (13) Duplicate-ID resolution flipped to first-wins. Bundled plugin:
          entries cannot be silently shadowed.
     (14) Self-diagnostic ID naming convention documented (diagnostic-
          infix reserved for runner-level findings; engine-input
          failures use aspect-state form).
     (15) Internal path → runner field rename + redaction-AC.
