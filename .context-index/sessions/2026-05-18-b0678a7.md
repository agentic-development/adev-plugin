## Intent

fix(tests): retry cleanupTempDir to absorb ENOTEMPTY race on macOS

The cli-e2e suite installs the plugin into a temp HOME, which causes
providers/opencode to symlink the plugin tree into the temp dir. On
macOS the recursive rmSync occasionally hits ENOTEMPTY when its
directory walk races with symlink targets still being written or
finalized — observed flake at tests/cli-e2e.test.mjs:91 ("installs
both providers with multiple --provider flags") in multiple recent
/adev:validate runs (PRs #141, #145).

Node's rmSync has built-in retry: pass maxRetries: 3, retryDelay: 100
to absorb the transient races without papering over genuine cleanup
bugs (3 retries x 100ms = 300ms upper bound on cleanup latency, which
is still well under the 30s test timeout).

Verified: previously-flaky test passes in 5 consecutive runs;
full npm test passes 3314/3316 (2 todo, 0 fail) post-fix.
