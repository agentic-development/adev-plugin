## Intent

test(validation): lifecycle + skill-doc coverage for atomic validate report (issue-496)

Adds two test layers above tests/cli/artifact.test.mjs:

1. tests/integration/cli-lifecycle.test.mjs — new scenario
   "validate report commit: write-tmp → adev artifact commit produces
   the canonical .validate.md atomically (issue-496)". Walks specify
   → review → plan → implement and starts validate, then exercises
   the two-step write: writes .validate.md.tmp via fs.writeFileSync,
   asserts the canonical .validate.md is absent before commit; runs
   the negative path (zero-byte tmp → exit 1 with tmp preserved);
   commits the real body; asserts tmp gone, canonical file present
   with matching content; re-runs the commit with a second body to
   prove renameSync overwrites cleanly; verifies no lifecycle event
   was emitted (artifact commit is a filesystem op, not a step).

2. tests/skills/validate-atomic-report-write.test.mjs — new doc test
   asserting skills/validate/SKILL.md (a) references the .tmp suffix,
   (b) invokes `adev artifact commit`, (c) passes --kind validate
   and --spec, (d) explains the atomic / mid-write rationale, and
   (e) does NOT contain a regression-shaped direct write to the
   canonical .validate.md path. Locks the verb to the skill so a
   future edit can't silently revert the protocol.
