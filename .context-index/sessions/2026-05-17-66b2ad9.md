## Intent

feat(tree-sitter-repomap): implement non-code reference detection

Closes the codehealth false-positive gap surfaced in the 2026-05-17 report
by teaching the repomap to recognize two reference sources beyond JS imports:

1. SKILL.md prose mentions of source files emit `doc-reference` edges.
2. package.json:exports entries tag FileNodes with `public-api-entry`.

The ranker runs both contributions as post-rank annotations on `references`
counts and `referenceSources[]` labels; the PageRank `score` field is
untouched and the sum-to-1.0 invariant is preserved.

In regex mode, both scanners still run, but their output is rendered only
into `repo-map.md` — no JSON artifacts — preserving the charter invariant.

  referenceSources?)
