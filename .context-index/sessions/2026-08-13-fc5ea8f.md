Two accuracy fixes found while reviewing revision 3, both the same defect
shape the earlier rounds caught.

"Define the 12 strategy types ... | implemented". registry.mjs has 9, and
that row's Status column is the charter's only assertion of CURRENT state,
so it claimed a 12-strategy registry was already shipped. The description
is now count-free; the three revision-5 capability rows carry the
extension to 12. Forward-looking counts in Interface Contracts and
Invariants are target-state prose and stay.

mechanism that did not exist. Its replacement — a checked-in deferral
policy file — invents a NEW artifact, and revision 3 read as though the
file already existed. It is now labelled explicitly as introduced by this
spec, with a proposed path (.context-index/governance/deferrals.yaml,
beside the existing governance policy files), a minimal schema, expiry
semantics, absent-file behaviour (empty list, so no operator_deferred is
accepted), a Module Impact Map row, and an acceptance criterion marking
the final location and format as a human decision.
