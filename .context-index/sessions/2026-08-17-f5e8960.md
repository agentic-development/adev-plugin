## Intent

feat(review): add per-pack delivery field defaulting to inline

BEH-9 (first half): resolveExtends now resolves a closed-enum `delivery` field (`inline` | `manifest`) with the same precedence as max_file_bytes / max_total_bytes — nearest declaration walking child to root wins — defaulting to `inline`. Every declared value in the chain is validated, so a typo in an ancestor the child overrides still fails loud with INVALID_PACK_DELIVERY and returns early like CONTEXT_PACK_CYCLE / UNKNOWN_CONTEXT_PACK (no delivery key, no silent fallback). renderPack already bails on resolved.errors, so it needed no change; manifest rendering behavior is deliberately NOT implemented here.
