## Intent

fix(unified-gates): position-aware path severity and precise CI matching

Two findings fired on healthy projects and would have taught operators
to ignore the doctor:

- 'npm run build && cd dist && npm test' is an ordinary gate and dist/
  is gitignored in most projects. path-gitignored now reports error only
  when the path appears in the gate's FIRST sub-command (nothing ran
  that could have created it — the repo-C case), warning otherwise.
  path-missing likewise fires only for first-sub-command paths.

- ci-gate-not-invoked fell back to the bare executable token, so a gate
  of 'npm test' matched any workflow containing 'npm ci'. The finding
  was effectively unfirable on every JavaScript project. Match
  candidates are now the command, its resolved chain, and '<pm> run
  <script>' spellings; the bare token counts only when distinctive.

Hygiene Pass 8's example output now carries measured counts (451 vs 326
under sh) rather than numbers copied from a stale comment.
