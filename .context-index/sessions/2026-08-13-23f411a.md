## Intent

fix(test-strategies): revise the four non-code strategy specs to revision 2

Addresses all 13 blocker entries from review round 1 via
`adev specify revise` (rev 1 -> 2, blockers sidecars cleared,
spec_revised events emitted).

Structural (SA-1, SA-2): the detection-cascade claims were
unimplementable. detectTaskStrategy is a fixed linear rule list, so
"checked before fixture" is not expressible for a new rule. All three
profiles now APPEND at the end of the cascade and state their accepted
consequences explicitly — models/**/*.sql stays fixture, threshold keeps
k6/locust/artillery/*.bench.*, and snapshot never claims image
extensions. No shipped rule is reordered or modified. The unachievable
"visual wins for a PNG baseline" AC is replaced with the honest note
that such a path resolves to unit today and this spec does not change it.
Multi-path resolution (first path wins, not most-specific rule) is now
stated. tolerance drops its claim on data_quality/dq/expectations, which
are Great Expectations and Soda Core layouts already inside fixture's
declared tool domain.

Structural (SA-3): all three profiles now define seed_data_rule and a
non-empty permitted_tools default, without which loadProfile() falls back
to unit and the "loads without fallback" AC could never pass.

Structural (SA-4): strategy_verification gains strategy-conditional
baseline_checksum and baseline_captured_at, giving the snapshot profile's
post-hoc-baseline and write-once rules a durable substrate. Until that
event is approved, both rules are documented as advisory rather than
implying enforcement that does not exist.

Security (SEC-1): commands recorded in handoff blocks must reference
credentials only via named env vars, matching the infra_requirements
probe constraint. Adds *_CREDENTIAL_IN_COMMAND per profile, plus
path-containment codes for baseline locators and band files, and a
mask-list-vs-schema check for snapshot.

Security (SEC-2): operator_deferred is no longer a self-declared source.
The recording verb reads hook-injected Author-type/Operator provenance
and ignores any caller-supplied source; agent provenance is rejected, not
downgraded. Without this the reason code was a fresh way to relabel the
same 235-of-391 silent skip.

Security (SEC-3): unmet_requirement is a name, never a message —
populating it from probe_error would write unsanitised stderr, which
routinely echoes connection strings, into committed JSONL.

Consistency (CON-1, CON-2, CON-3): LEDGER_SPEC_PATH_UNRESOLVED replaces
the INVALID_SPEC_PATH collision with specify's hard-failure contract;
RECON_ renamed to RECONCILIATION_ to match the strategy-id prefix
convention; the charter's Strategy Type Registry row updated 9 -> 12.

Also: one authoritative shared 9 -> 12 update table (13 sites, including
the ID arrays and describe titles the first draft missed) replaces three
divergent copies; a retroactivity cutoff so landing the ledger does not
mark every pre-existing task unverified on day one; and ledger ACs split
into lib-enforceable / SKILL.md-dependent / approval-gated tiers.

npm test: 5474 pass, 0 fail, 2 todo — unchanged from baseline.
