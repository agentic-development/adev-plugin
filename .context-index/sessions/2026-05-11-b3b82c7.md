## Intent

ci(release-please): drop sticky `release-as: 0.25.0` pin

release-please's `release-as` directive forces the next release to a
specific version regardless of conventional-commit math. It was set to
ship the 0.25.0 cut via PR #80 but was not removed afterward, so every
subsequent commit on main wakes release-please up and it dutifully
proposes another 0.25.0 release (see #96 — a no-op compare of
adev-cli-v0.25.0...adev-cli-v0.25.0 that would fail GitHub Release
creation on the existing tag and 403 on npm publish).

Removing the pin so release-please computes the next version from
commits since the adev-cli-v0.25.0 tag. After this merges and #96 is
closed, the next release PR should naturally propose 0.25.1 with the
npx-bin-alias fix from #95 as its sole entry.
