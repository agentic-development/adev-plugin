In-review fix to regression-prevention implementation: the hook was
implemented as a whole-blob check, contradicting spec Behavior 3 ("adds
new content") and Error Cases ("hook checks only `+` lines"). Repaired
to diff-based for Behavior 3 (pattern check on added lines only); kept
blob-based for Behavior 4 (per-H3 both-forms state invariant). The
`adev <verb>` detection in Behavior 4 was also tightened to match only
inside fenced code blocks — prose mentions like "the adev plugin" no
longer trigger the both-forms check. Two new regression tests lock in
both fixes. This unblocks the upcoming inline-node-extraction-sweep,
whose per-skill atomic PRs leave other H3 sections with pre-existing
inline-Node that a whole-blob check would have rejected.
