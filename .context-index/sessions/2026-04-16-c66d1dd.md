## Intent

feat(task-management): next_action and free-text type fields (issue-77)

Implements next-action-and-type-fields spec.

- interface.mjs: validateIssue accepts free-text type with "task" default
  (was strict enum bug/feature/task); throws INVALID_TYPE for empty/
  non-string. Adds next_action: string|null field; throws
  INVALID_NEXT_ACTION for non-string. Issue typedef extended.

- file-adapter.mjs: ISSUE_HEADER and ISSUE_SEPARATOR gain Next-Action
  column (between Notes and Created). parseIssueRow handles both
  12-column (legacy) and 13-column (new) rows; missing column reads
  as null. serializeIssueRow escapes newlines to spaces.

- beads-adapter.mjs: next_action stored in .beads-map.json sidecar
  metadata alongside epicId/planRef/planTask. Round-trip verified.

- constitution-template.md: brief Task Management section noting the
  next_action update convention for skills.

  test updated — used type: "epic" which is now valid free-text.
  Replaced with type: "" and type: 42 cases.
