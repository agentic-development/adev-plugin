feat(task-management): tiered hierarchy and tree walking (issue-76)

- New module: lib/issues/id-utils.mjs
  - parseId(id) → {tier, depth, parent_id, prefix, counter, legacy}
  - nextChildId(parentId, tierPrefix) — monotonic per-parent counters
  - getTierConfig(manifest) — manifest tier_prefixes with defaults

  (cascade-aware), listAll; constructor accepts opts.tierPrefixes

  legacy IDs return empty list

  added to Issue typedef

  (commented), default {e: Epic, f: Feature, t: Task}
