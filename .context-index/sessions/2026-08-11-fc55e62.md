## Intent

docs(test-strategies): rev 7 — one missing-input policy, per-task parse, floor_inputs persisted

Resolves all seven round-6 blockers plus the carried warnings.

The unifying decision: MISSING_FLOOR_INPUT is removed entirely. Under an
advisory floor, halting a task protects nothing — so every zero-path case
(absent block, prose-only block, inline label without a path) degrades
identically per task: the sensitive-path leg is skipped and the assignment
records floor_inputs: "unavailable". The risk_level and boundary legs still
run. The rejected fail-closed alternative is documented in a decision note
so reviewers see it decided, not missed.

The **Files:** parse now covers both shipped shapes (block form and inline
label form), the separate required **Tests:** field, a pinned path-token
predicate, backtick unwrapping, prose tolerance, and line-range stripping —
keyed per task, because the format is per task and shipped plans cover the
block only partially (a per-plan exemption misfit the format; the round-6
root cause was measuring plans when the unit is tasks).

floor_inputs is persisted end to end: Behavior 13 payload, resolveTestDepth
return, the event's Interface Contract row, ADR-0016 §4, and three distinct
floor states in explain (held / not held / path leg not evaluated).

Warnings swept: status-integration task row added; append-order tie-break
pinned for "most recent"; INVALID_SENSITIVE_PATHS now degrades to the
built-in set instead of halting repo-wide; PATH_OUTSIDE_ROOT aligned with
shipped code and WORKSPACE_ROOT_REFUSED split out; error codes wired into
behaviors both ways; no-echo rule scoped to explain/task paths; affects:
fixed to module slugs; the unreproducible "103" figure replaced with a
command that reproduces (109); KL rewritten to six honest entries incl.
the routine-case wording and the nothing-forces-the-call limitation; docs
table now requires the advisory statement in governance.md and
test-strategies.md; ADR records the descope in Status and Consequences.
