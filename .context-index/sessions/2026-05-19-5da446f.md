## Intent

test(hooks): integration tests for post-commit self-skip

Adds tests/hooks/post-commit-self-skip.test.mjs covering all six spec
behaviors of the .githooks/post-commit self-skip guard: sessions-only
skip with stderr diagnostic, mixed-commit capture, non-session capture,
prefix-collision capture (sessions-archive/, sessions.bak), stderr-only
diagnostic verification, and .session-tracking.jsonl preservation on the
skip path (review note CON-1).

The setupHookEnv() helper symlinks the plugin's lib/ into the tempdir
(so the hook's `import './lib/session-summary.mjs'` resolves) and adds
the symlink to .git/info/exclude (so `git add -A` does not stage it into
the test commit, which would defeat the sessions-only skip). The JSONL
test seeds the tracking file after the commit but before the hook runs
to model the real-world flow where the JSONL accumulates between commits
via the pretooluse hook and is never part of any commit.
