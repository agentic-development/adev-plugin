## Intent

feat(lib): detect inline Routing blocks without sidecar regardless of git history

Adds a working-tree inspection branch to detectMutatedPlans. When a plan
body contains inline **Routing:** / **Scores:** / **Rationale:** blocks
and no sibling <plan-stem>.routing.md exists, the detector emits a
PLAN_MUTATED_WITHOUT_SIDECAR violation. This catches the mutate-then-
single-add-commit pattern that the legacy --diff-filter=M history check
misses (e.g. cursor-provider plans committed as single A commits).

Three new fixtures cover the three cases: clean-plan (pass),
mutate-then-single-add (flag), sidecar-present-plus-inline (tolerate
inline as legacy migration noise).
