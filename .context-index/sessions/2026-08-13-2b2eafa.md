## Intent

revert(sample): drop the /adev:sample --test carve-out, defer to issue-616

Behavior 14 of test-helper-inventory.spec.md amended /adev:sample's Red
Flags rule -- which a human wrote as an absolute "Never ... include test
files as golden samples" -- to apply to *implementation* samples only,
and added a --test curation mode plus a Sample kind field in the sample
template. The spec flagged it for independent veto precisely because it
edited someone else's absolute rule.

Reverting for scope, not merit: amending /adev:sample's contract is a
change to a different skill and should be reviewed in a PR owned by that
skill, not carried along by a test-helper-inventory change. Tracked as
issue-616 with the prior implementation recoverable from this branch's
history.

Nothing here regresses. The inventory never depended on the curation
path: Behavior 6's second clause classifies a sample as a test sample
when its `Source:` path is test-shaped, and collectTestSamples() still
honours a hand-written `Sample kind: test` marker. The gap is only that
no adev command emits one.

The three injection assertions covering Behavior 14 are REMOVED rather
than skipped -- they described deliverables this branch no longer ships,
and a skipped test asserting reverted behavior is exactly the silent-skip
pattern epic-108 exists to eliminate.
