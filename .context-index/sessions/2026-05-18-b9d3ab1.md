## Intent

fix(repomap): include .mjs in the typescript language extensions

The typescript language plugin only listed .ts/.tsx/.js/.jsx, so the
repomap silently skipped every .mjs file. In a pure-ESM project like
this plugin (494 .mjs files, zero .js outside test fixtures), the
resulting symbol-ranks.json and dependency-graph.json contained only
test-fixture symbols — making /adev:document, /adev:codehealth, and
/adev:hygiene drift detection effectively blind to real source.

Changes:

- lib/repomap/languages/typescript.mjs: add ".mjs" to the extensions
  list. Tree-sitter-typescript parses .mjs identically to .js.

- tests/repomap/parse.test.mjs: regression assertion that .mjs is in
  the extensions list. Would have failed before this fix.

- lib/repomap/index.mjs: update a now-stale comment that referenced
  the old ".ts/.tsx/.js" glob as the example for the stub-node path.

- docs/architecture.md, docs/modules/*.md, docs/GENERATED.md: first
  meaningful run of /adev:document on this codebase. Generated after
  the .mjs fix, since previous runs against the all-test-fixture
  symbol ranks produced empty Key Exports tables for every module.
  These files carry the adev:generated / adev:human marker pair and
  are owned by the skill above the marker.
