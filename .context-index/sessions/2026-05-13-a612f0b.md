## Intent

feat(agent-reliable-state-artifacts): replace viz/build.mjs inline markdown parser with adapter

Previously viz/build.mjs read .context-index/tasks/tasks.md directly via an
inline parseMarkdownTable helper. This left it stuck on the legacy markdown
format while the rest of the codebase migrated to JSON. Switch to
getIssueManager(manifest, root) and let the adapter handle backend selection,
including the read-only-deprecated FileAdapter fallback for projects still
on tasks.backend: file.

Drop the now-unused parseMarkdownTable. The adapter rejects invalid rows that
the old parser silently accepted, so node counts decrease slightly (-10 of
3038) — an improvement, not a regression.
