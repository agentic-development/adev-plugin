## Intent

feat(agent-reliable-state-artifacts): JSON issue board + adapter

Adds .context-index/tasks/tasks.json as the new issue board format with
JsonAdapter implementing the unchanged IssueManagerInterface. Extracts
parseTasksMd into a shared lib/issues/markdown-parser.mjs consumed by
both the legacy FileAdapter and JsonAdapter's legacy-read fallback.

canonical advisory. Registry adds "json" to SUPPORTED_BACKENDS and
flips the default; emits one-time DEPRECATED_BACKEND warning on "file".
Atomic temp-then-rename writes mirror lib/build-state.mjs::atomicWriteJson.
Board-granularity invariant (no Issue with both planRef and planTask)
enforced by JsonAdapter._validateBoardGranularity in create/update.

concurrent, perf, markdown-parser).
