## Intent

docs(coordination): document leases, widen the shadow-path guard, bump to 0.28.0

Follow-ups the three parallel units each left outside their own file scope.

Lease semantics in the two preflight skills. Both said a claim is never taken
over autonomously, which stopped being true when claims became leases: exit 0
now also means "you inherited an expired one". A skill documenting only the
refusal reads as though exit 0 always means the issue was free, and never
surfaces the displaced owner — who may be a crashed session about to resume.
The wording now separates a live claim (refused, exit 2, never forced) from
an expired lease (inherited at exit 0, takeover block reported), and the tests
assert both halves rather than just the halt.

The issue-607 architectural guard swept lib/, hooks/, cli/, and scripts/
instead of the two files already known to be broken — a two-file allowlist
only catches the two regressions you already found. The sweep is currently
clean; hooks/_execution-state.mjs was already importing the library.

docs/cli-reference.md listed `issues` as "e.g. backend migrate" and knew
nothing about claim/release (shipped in da45a279), stale, or coordination
scan. Three verbs were reachable only by reading source.

version-parity caught a third file CLAUDE.md's parity rule does not name —
.cursor-plugin/plugin.json — which is the test earning its keep.
