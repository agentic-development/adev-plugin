## Intent

feat(agent-reliable-state-artifacts): markdown rendering layer + migrate CLI subcommand

Adds the read-only markdown rendering layer that produces human-readable
views from authoritative JSON/JSONL state on demand:

- lib/issues/render-markdown.mjs — renderTasksMd(board) pure transformer
  plus writeTasksMd(projectRoot) atomic I/O wrapper, with the 6-rule
  escape pipeline (newline normalize, slot-context collapse, HTML escape,
  markdown structural escape, length truncation, null placeholder)
- lib/lifecycle-state.mjs — full bodies for renderMarkdown(state) and
  listLifecycleStates(projectRoot), replacing the foundation stubs
- cli/index.mjs — wires `adev status --render` and `adev status --pipeline`
  with SA-2 advisory-skip exit-code semantics and SA-3 composite rule;
  also wires `adev migrate` and its --dry-run / --artifact=<name> flags

Generated files carry a non-editable DO NOT EDIT header; SEC-1 defuses
"-->" tokens in the interpolated source slot. SA-1 ensures writeTasksMd
consumes public JsonAdapter.list/listEpics (not _read). CON-5/CON-6
enforce positive isDirectory() check and best-effort cleanup-on-failure.
Architectural tests assert no skill autonomously invokes --render and
renderMarkdown never imports domain-config.

atomic, projection, CLI render, CLI pipeline, architectural).
