## Intent

refactor(setup): delegate prototype-server ensureGitignore to managed block

Replaces the legacy lazy `.adev/`-append in lib/prototype-server.mjs with
a one-line delegation to ensureManagedBlock from gitignore-installer.mjs.
The canonical block already lists `.adev/` (entry 18 of
MANAGED_GITIGNORE_PATHS), so the prototype workspace stays ignored.

SA-4: prototype path force-installs the block — does NOT honor
setup.managed_gitignore: false. Prototype boot specifically needs `.adev/`
ignored to operate safely; gating on the manifest knob would leak
`.adev/` artifacts into git for users who disabled the scaffold-time
install.

Removed: pattern-aware `.adev`/`.adev/**`/`*` detection (now handled by
the paired-marker block's idempotent splice). Tests updated to assert
delegation behavior (block markers + .adev/ present, idempotent re-run).
