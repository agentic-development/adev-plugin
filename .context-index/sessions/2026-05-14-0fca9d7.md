## Intent

feat(cli): revise CLI charter to rev 3 (drop single-file constraint)

Lands the prerequisite for driver-substrate.spec.md. Rev 3 changes:

  - Drop the single-file constraint; per-verb lifecycle helpers live in
    lib/cli/<verb>.mjs while cli/index.mjs remains the single binary
    entry point and dispatcher.
  - Declare the Map-keyed verb-registry pattern and the uniform module
    contract: run({projectRoot, argv, manifest}) + help() + optional
    LIFECYCLE_STEP export.
  - List the legacy commands (install/upgrade/uninstall/init/extension/
    status/migrate/help) under a dedicated subsection; clarify that
    legacy adapters implement the .run/.help surface but are exempt
    from the parameter contract (dispatcher discards the args).
  - Declare the lifecycle driver surface verbs landed by the
    cli-driver-surface charter (gate require, diagnose) and reserve
    slots for future verbs per inline-node-extraction-sweep.
  - Add constraints: exit codes 0/1/2 per Constitution Principle 4,
    stderr sanitization for verb names + error messages (per
    driver-substrate.spec.md SEC-2, scoped to dispatcher stderr only —
    intentional ANSI on stdout is unaffected), backwards-compat on
    legacy verbs (no silent removal).
  - Update Key Files to include lib/cli/<verb>.mjs, per-verb tests,
    and the pattern test enforcing the contract.
