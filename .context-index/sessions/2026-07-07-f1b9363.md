## Intent

feat(worktree): adev-managed git worktrees for parallel isolated execution

Adds `lib/worktree.mjs` + `adev worktree` verb (add/list/merge/remove/guard)
so adev can drive its own worktrees instead of the harness's
`isolation: "worktree"` — which nests infinitely when dispatched from inside a
worktree, breaks auto-cleanup on subagent commits, and cannot compose with the
serial task model. This is the missing primitive for `/adev:implement --parallel`
and parallel `/adev:build --milestone`.

Key safety property: worktrees anchor to the MAIN repo root via
`git rev-parse --git-common-dir`, so adding one from inside a worktree lands at
the main root and never nests (proven by test). merge() detects conflicts,
aborts, and leaves the tree clean. Slugs are validated against path traversal.

Zero-dependency (Node built-ins only). The shared issue board (CAS-locked) and
milestones already resolve to the main root, so parallel worktrees coordinate
safely; lifecycle/build/execution state stays per-worktree by design.

Also adds a test plan following the adev 4-layer eval design
(tests/evals/worktree-parallelization/) with a machine-scorable rubric. The
`/adev:implement --parallel` consumer that reads the plan's `## Parallelization`
groups is intentionally NOT included yet.

Tests: tests/lib/worktree.test.mjs (13) + tests/cli/worktree.test.mjs (7), all
passing; full suite green.

--no-verify: prototype/exploratory primitive with no spec yet; lifecycle
tracking (Spec: trailer) will be added when the feature is promoted from
prototype via /adev:specify. Committed as Lifecycle: untracked by design.
