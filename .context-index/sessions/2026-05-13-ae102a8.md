## Intent

chore(agent-reliable-state-artifacts): run adev migrate — convert state artifacts to charter-era shapes

Runs `adev migrate` against this project. Converts the four legacy state artifacts
to their JSON/JSONL successors and updates references:

- tasks.md → tasks.json (version: 2, 68 epics, 145 issues — clean post-granularity-cleanup)
- build-state/*.json → lifecycle-state/*.jsonl (10 per-spec event logs)
- milestones.yaml → milestones.json (written to main checkout per worktree-shared
  storage; commit that separately on the main checkout branch)
- constitution.md Context Routing row: "Build state" → "Lifecycle state"
- 96 plan files: stale path references rewritten by the plan-advisory step

Manifest backend flipped: tasks.backend: file → json. The JsonAdapter is now
authoritative for all writes; reads fall back to legacy markdown only if
tasks.json is absent (per json-issue-board-adapter.spec.md).

Legacy files intentionally retained on disk (per spec — operator-manual delete
during the one-release-cycle deprecation window):
  .context-index/tasks/tasks.md          (still present)
  .context-index/build-state/*.json      (still present)

No code changes. All 2446 tests pass.

Follow-up obligations:

1. `/adev:sync` to propagate the constitution Context Routing change to CLAUDE.md.
2. File a bug against lib/migrate-state-artifacts.mjs::migrateTasks: it writes
   tasks.json to the worktree's cwd while migrateMilestones uses
   resolveStorageRoot() and writes to the main checkout. The two migrators
   disagree on path semantics in worktrees. The runtime JsonAdapter sides with
   resolveStorageRoot(), so tasks.json in a worktree context will not be read
   by the adapter on a sibling worktree until the migration commit lands on
   the main branch.
3. Delete legacy artifacts (tasks.md, build-state/, milestones.yaml) after the
   one-release-cycle deprecation window.
