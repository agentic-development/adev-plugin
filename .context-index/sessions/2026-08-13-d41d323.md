## Intent

feat(gates): ship a live integration tier in every domain starter

The software starter and both extension overlays declared a fast tier only,
so a scaffolded project could never reach the shipped tier engine. Append an
error-severity `integration-test` gate running
`[npm, run, --if-present, test:integration]` to all three: `--if-present`
exits 0 when the script is undefined, so the gate is live and free on a fresh
scaffold and starts enforcing the moment the script exists.

Per D2 the id is deliberately shared with the template's integration entry —
a governance `command: ""` sentinel is rejected by validateGate before it can
reach byId, so it never clobbers the working domain gate and still emits a
named INVALID_GATE warning. The new test reads all three shipped files from
disk and asserts named fields only (D3: mergeGates narrows entries and
injects __source, so deep-equality would fail for unrelated reasons).
