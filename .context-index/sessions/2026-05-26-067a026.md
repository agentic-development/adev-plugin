## Intent

fix(install): show picker menu and ship bundled domain extensions

The init-time domain picker prompted "Pick a domain (1-N) [1]:" without
ever listing the options, and the bundled `extensions/` tree was missing
from `package.json` `files:`, so every npm install dropped the catalog
entries with a warning leaking the internal `_npx` cache path.

- Add `extensions/` to the published file list so data-engineering,
  process-automation, and example-validation-check ship with the package.
- Print the labeled options before prompting in `runPicker` via a new
  optional `print` dep (defaults to `console.log`; `cli/index.mjs` wires
  the install-pipeline `log` helper so the menu picks up the standard
  2-space indent).
- Soften the missing-path advisory to report the catalog-relative path
  with a "likely a packaging issue" hint instead of dumping the absolute
  resolved path.
