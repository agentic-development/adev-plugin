pr-body-composition — BLOCK (5 blockers)
Two themes. Undefined input contracts: the /adev:validate report is named
with no path convention, no extraction grammar and no fallback ladder, and
its own producer forbids re-parsing it (skills/validate/SKILL.md:405 —
validator outcomes are canonically state.steps.validate). The UNKNOWN
invariant is unimplementable because routing.json carries no files[] and
the spec never says where the task universe comes from. Output escaping is
under-specified for the actual threat: no path containment on
trailer-derived paths (CWE-22), the escaping set omits the markdown table
pipe and does not cover rationale despite it being "reproduced verbatim",
and marker literals are not neutralized — which lets a crafted trailer
forge the closing marker and defeat the authorship boundary this module
exists to enforce.

pr-body-advisories — BLOCK (6 blockers)
One root cause behind all four structural blockers: the ## Parallelization
grammar was designed against two hand-picked samples, and the spec claimed
it was "verified against real shapes". Measured against all 138 plan files,
63% reach rung 1, 3% reach rung 2, and 34% reach no defined rung at all —
rendering a silent empty reading order with no annotation. That is exactly
the failure the ladder was written to prevent, firing on a third of the
corpus. Also: conforming lines that yield zero tasks, two contradicting
task-extraction rules, 35% of plans missing the ## Task Summary that rungs
2 and 3 depend on (including all four plans that actually reach rung 2),
and lib/parallel/groups.mjs already parsing the same section under an
incompatible grammar while the charter never declares /adev:plan as a
dependency.

review-packet-template — PASS_WITH_NOTES (1 warning)
The reviewer independently verified both territory claims: neither cicd nor
copilot-provider owns .github/pull_request_template.md, and both
skills/validate:566 and skills/implement:649 carry bare gh pr create.
CON-1: "emits any of the four packet headings" needs tightening to mean a
line beginning with "## ", because pr-body-advisories quotes ## What inline
and a naive substring interlock test would fail on the sibling's designed
behavior.
