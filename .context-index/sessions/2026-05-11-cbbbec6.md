## Intent

fix(cli): resolve npx invocation failure from in-tree workspaces

`npx @adev-org/adev-cli <cmd>` fails with `sh: adev: command not found`
when run from the plugin's own source directory. npm derives the
candidate bin name from the package-name segment (`adev-cli`), which
did not exist in `bin` — only `adev` did. Running from any other CWD
worked because the registry-fetched install materialized the bin shim,
but contributors and the SessionStart upgrade hint hit the failure mode.

- Add `adev-cli` as a bin alias pointing at `./cli/index.mjs` so the
  package-name-derived lookup resolves in every context.
- Pin `@latest` in the upgrade hint emitted by `cli/index.mjs` and
  `hooks/session-start.sh` to defend against stale `~/.npm/_npx/`
  cache entries reusing an older un-aliased version of the package.
