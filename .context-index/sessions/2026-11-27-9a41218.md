## Intent

test(implementation): make the BEH-15 fixture's first review fail on every implementation

The non-convergence fixture's trigger was an acceptance criterion that the
plan's given code did not meet. In four of four live runs the implementer met
the criterion anyway, the review passed and the run was a fixture miss.

The trigger is now a spec/constitution conflict split across the review
boundary. The spec says normalizeSku and signAudit throw. The constitution's
Non-Negotiable Principle 4 says no exported src/ function throws, outranks
the spec, and says the difference is never a blocker or a question. The
implementer is given the Non-Negotiable Principles. The Stage 1 and
synthesized reviewers get the acceptance criteria and at most the Coding
Standards section. No code meets both, so every first review sees an unmet
criterion. The plan's task text no longer carries code, and preseeded Task 1
follows the principle so Task 2 has a precedent. The smoke suite pins these
invariants.
