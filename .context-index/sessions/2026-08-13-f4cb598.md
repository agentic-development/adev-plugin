## Intent

feat(issues): give claims a TTL, a takeover path, and a stale report

Closes issue-610. Claims landed in da45a279 with expiry explicitly out of
scope, which left a dead session able to hold an issue forever. That is worse
than no gate: an unreleasable lock trains operators to bypass the gate, and a
bypassed gate protects nothing.

TTL is manifest.tasks.claim_ttl_minutes, default 240 — longer than a long
agent session, shorter than a working day. 0 disables expiry (prior
behaviour). Resolution follows the cas_max_retries / cas_lock_stale_seconds
pattern already in JsonAdapter, and `adev issues stale` reads the TTL off the
adapter instance so the report and the gate cannot disagree.

Staleness is fail-closed: an owner whose claimed_at is missing or unparseable
counts as LIVE, so a malformed row never hands work away. A live claim by
another owner is still refused with ISSUE_ALREADY_CLAIMED; a stale one is
taken over with a fresh claimed_at. The check stays inside _withCas, sharing
one Date.now() between check and write, so N concurrent claimants on a stale
issue still yield exactly one winner — asserted, not assumed.

The displaced owner is reported, not persisted: returned as an ephemeral
takeover{} on the claim result and printed. Persisting it would mean
threading a fifth field through the fixed whitelist in validateIssue, whose
failure mode is a silent drop — create() reporting success and storing
nothing. That cost buys history the board does not otherwise keep.

release() is left lease-blind on purpose. Takeover is claim's job; a second
bypass shape on this gate would train the behaviour the gate exists to stop.

`adev issues stale [--json]` is read-only. It reports unexpirable rows
(owner with no claimed_at, which can never expire on their own) separately,
and excludes closed-but-claimed issues, which close() never clears and which
would otherwise accumulate as un-actionable noise.

The hard-coded 2026-08-12 timestamps in claim.test.mjs were replaced with
freshly generated ones: left alone they would have aged past the lease and
silently reclassified themselves from idempotent-reclaim tests into takeover
tests.
