## Intent

fix(test): discover tests in Node instead of a shell glob

`npm test` ran `node --test tests/*.test.mjs tests/**/*.test.mjs`. npm
executes scripts through `sh`, which does not implement `**` — it
degrades to a single `*`, so the second pattern matched exactly one
directory deep. Every test nested further down was silently never handed
to the runner: 77 of 416 files, including ~50 real unit suites under
tests/lib/{issues,domains,parallel,extensions} and tests/diagnostics.
Nothing errored and nothing reported a skip; the suite simply passed on
the subset it received, and CI inherited the same gap.

Move discovery into scripts/run-tests.mjs (Node built-ins only) and drop
globs from the npm script entirely. Files are partitioned into three
buckets that provably cover the tree:

  default (392)  npm test — the quality gate
  evals   (19)   npm run test:evals — harnesses needing docker, an API
                 key, or local session JSONL; running them by default
                 makes the gate depend on machine state
  excluded (6)   nested fixture projects' own suites (test data)

The nested-project rule is derived from the tree rather than hardcoded:
a directory under tests/ with its own package.json is a nested project,
and only its own tests/ subdir is excluded — so our harness files that
sit beside a fixture's package.json are kept.

This is exclusion, not the invisibility it replaces: the partition is
printed on every run, `npm run test:all` reverses it, and
tests/test-discovery.test.mjs asserts the three buckets cover every
*.test.mjs on disk with no overlap, that depth>=3 files are found, that
every exclusion has an owning package.json, and that the npm script
contains no shell glob.

Restoring discovery leaves the gate RED: 5106 tests, 4 failures, all in
code that had never executed in CI (overlay type count, UNIT_PROFILE
permitted_tools, JsonAdapter concurrent appenders). Those are tracked
separately. Red and accurate beats green and partial.

Trailer note: package.json is also listed in the source manifest of
verbosity-axis-and-output-trimming.spec.md, but this change touches only
the test scripts, not output verbosity. The behavior implemented here is
measurement-integrity behavior 1.
