## Intent

fix(plan-immutability): block inline routing annotations via PreToolUse hook

A new PreToolUse hook (hooks/plan-body-write-guard.sh) refuses Write/Edit
tool calls that introduce inline **Routing:** / **Scores:** / **Rationale:**
blocks into *.plan.md files. The hook fires before the write lands — the
harness exits 2 and the agent must call adev route emit-sidecar instead, as
plan-routing-sidecar.spec.md Behaviors 6-7 require.

Root cause of issue-537: the skill, lib, CLI verb, and detector were already
correct (corrective commits 8f8b9613, 1335b217, f81802a3, 4d389a11 all
landed before the init-extension-picker incident), but nothing prevented the
agent from ignoring Step 4 of skills/route/SKILL.md and inlining annotations
anyway. 8bedda45 backfilled the missing sidecar by hand; this hook prevents
recurrence at tool-call time without relying on the agent's compliance.

Cursor and Copilot provider mirrors regenerated. Translation table extended
with a PreToolUse/Write|Edit row mapping to fail-closed Cursor preToolUse;
the Copilot matcher is auto-rewritten from Write|Edit to create|edit by the
existing TOOL_NAMES vocabulary.

Tests: 11 new hook tests cover allow/block/edge cases (non-plan paths,
.spec.md with the patterns in prose, clean plans, delete-only edits,
env-var vs stdin-JSON modes). Cursor drift test updated for the new pair
(7 → 8). Full suite passes (4061/4061 + 2 todo).

Resolves issue-537.
