## Intent

test(implementation): add a plain Claude Code arm, edge probes, patches and a blind judge to EV-1

The EV-1 harness gains `--arm plain`: the same sandbox, seed, spec and plan,
a plain-language prompt, no --plugin-dir, no ADEV_* env and an adev stub on
PATH. Every claude spawn passes --settings disabling every installed plugin
named adev, so the adev arms load only the ref's --plugin-dir copy.
--check-isolation prints each arm's argv and env delta, and --probe spends
one short claude -p per arm to confirm it from the init message and
transcript.

Every run now records process wall clock and wall_clock_source, node:test
counts, a 54-probe held-out edge battery (BEH-1..BEH-7) and its patch
(runBase..HEAD minus .context-index/). judge-runs.mjs scores anonymized
patches twice against judge-rubric.md, and --compare tabulates all arms
present. --evaluate's thresholds are unchanged.
