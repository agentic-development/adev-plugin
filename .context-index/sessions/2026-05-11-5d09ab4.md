## Intent

feat(extensions): accept path alias in domain-profile manifest

installExtension() previously required `provides.domain-profile.source_dir`
and `provides.domain-profile.name`. Extension manifests in the repo use
`path:` instead of `source_dir:` and omit the redundant `name:` field
(it duplicates the top-level manifest name). Accept either spelling and
fall back to `manifest.name` so first-party extensions work without
boilerplate.

Also adds Task 2 integration tests for both extensions: installExtension
end-to-end against a temp project, domain.yaml verification, loadDomainConfig
resolution to the domain-specific reviewer, and idempotent re-install.
