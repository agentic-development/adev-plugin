## Intent

docs(review): revise rev-5 review-gate amendment to rev 3 — address four rev-2 blockers

Rev-2 review returned BLOCK with 4 new blockers, all against text introduced in
rev 2. Two reviewers independently found the same absorbing-state defect.

SA-1 + CON-1 (convergent): rev 2's BEH-3a reconciled spec_sha across "a step" —
the whole step history, not one revision. The base fold is latest-revision-wins,
and the BLOCK->revise->re-review loop guarantees differing digests across
revisions for one step, so the "divergent" sentinel would latch on the first
retry and, the log being append-only, never clear. Every spec converging through
the designed retry path would become permanently un-plannable under strict mode
— this amendment at revision 2 would have blocked itself. BEH-3a now reconciles
only the latest revision's reports; byRevision[N].specSha carries per-revision
history as audit-only.

SEC-1: rev 2 scoped the digest to the body alone, leaving ALL frontmatter
unattested — including risk_level, charter, amends and target-revision, which
drive governance. A spec reviewed at risk_level: high could be flipped to low
after review (yielding require_hitl_approval: false, review_mode: quick,
test_depth: minimal) while an unchanged body digest still passed the gate: the
same CWE-345 surface this amendment exists to close, one level up. BEH-1 now
digests a canonical attested region — frontmatter minus an explicit denylist of
the four lifecycle-machine-written keys (status, updated, drift_detected,
source-manifest), sorted and serialized, then the body.

CON-2: rev 2 specified GATE_SPEC_SHA_MISMATCH as the GateError code, but
cli/index.mjs maps err.code === 'GATE_BLOCKED' to exit 2 and everything else to
exit 1, while every gate consumer keys on exit 2 — a distinct code silently
converts a gate block into a crash. The code stays GATE_BLOCKED; the mismatch
identity moves to a `reason` discriminator, and the constructor widens.

Acceptance criteria 16 -> 21, including regression ACs for each: mutating
risk_level alone must change the digest, rev-1/rev-2 digests must not project
"divergent", and a sha-mismatch GateError must still exit 2.

rev 2 -> 3, status review-blocked -> review-pending, sidecar cleared via
`adev specify revise`. adev diagnose clean.

Loop defect filed separately as adev-plugin-j7pq.9: the BLOCK->revise auto-retry
loop contains no authoring step, so these revisions were hand-authored before
invoking the mechanics verb.
