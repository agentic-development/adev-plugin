## Intent

chore(migrate): convert existing routing sidecars to JSON

Two existing routing artifacts migrated from the legacy markdown
shape (or the pre-rev-2 markdown sidecar) to the new JSON format
emitted by lib/plan-routing-sidecar.mjs.

- plan-routing-sidecar.routing.json (issue-526 spec): spec 1's
  plan was routed *before* its own SKILL.md rewrite landed, so it
  carried inline **Routing:** / **Scores:** / **Rationale:** blocks
  in the plan body and never had a sibling sidecar of any extension.
  Extracted all 8 inline entries (scores normalised from raw 0-5
  to 0-1) into a real .routing.json via `adev route emit-sidecar`.
  The inline blocks remain in the plan body as legacy noise; the
  detector now tolerates them because a sibling sidecar exists.

- review-block-auto-retry.routing.json (issue-527 spec): spec 2's
  routing was emitted as a .routing.md during the route step earlier
  in this session. Converted the 18 entries to the JSON format and
  deleted the old .routing.md. Per the new ADR-0012 closed enum the
  .md form is no longer permitted for the routing peer.

The detector flip in lib/plan-immutability.mjs means both plans
are now clean against the working-tree branch
(PLAN_MUTATED_WITHOUT_SIDECAR). The ~20 legacy plans across the
repo that still carry inline blocks without any sidecar remain
flagged — out of scope per plan-routing-sidecar.spec.md rev 2.
