## Intent

docs(lifecycle-event-log): amend rev 5 for review-gate integrity

The review gate accepts two verdicts it should reject, and both are gaps in
this spec's contract rather than implementation bugs — hence an amendment.

`requireGate` asserts only that the prior step completed with a passing
verdict. `reviewer_report` records no identifier for *which bytes* the
reviewer read, so a spec can pass review, be rewritten arbitrarily, and
still satisfy the gate. `revision:` does not close this: it is
author-declared, not content-derived, and a rewrite that skips the bump is
invisible.

Separately, `adev report --type step --status completed` validates `--status`
against the legal set and nothing else, so a terminal event can be forged
for a step that never started — producing a projection indistinguishable
from genuine completion.

Adds BEH-1..BEH-8 and five Error Cases rows (GATE_SPEC_SHA_MISMATCH,
SPEC_SHA_UNVERIFIABLE, SPEC_SHA_UNAVAILABLE, ORPHAN_STEP_TERMINAL, plus the
advisory-mode row). No existing row is modified. `spec_sha` is an optional
field on the existing `reviewer_report` variant, not a new CANONICAL_EVENTS
variant, so the ADR-0009 human-approved boundary is not crossed.

Design tension resolved in the spec: the base requires `requireGate` to
perform no I/O and to take resolved inputs from its caller, so recomputing a
digest inside it would break that contract. The signature becomes
`requireGate(state, stepName, { mode, currentSpecSha })` — the caller
computes the digest, exactly as it already resolves `mode`. Omitting it
skips the comparison under an advisory, so every existing call site is
unchanged (BEH-6).

Per operator approval: a missing `spec_sha` is never blocking (BEH-5), which
keeps the existing review history of all 254 specs valid; enforcement starts
with reviews recorded after this ships. The sha check runs only after the
existing status/verdict assertion, so a spec that failed the old gate still
fails it with the old code (BEH-4).

Behavior IDs start at BEH-1 in this amendment's own spec-scoped space. The
base is a legacy ordinal-bullet spec and is deliberately not retro-migrated.

The third defect on adev-plugin-j7pq.3 — a skipped review emitting PASS — is
scoped out: graduated-rigor-tiers.spec.md already replaced the legacy
`require_review: false` with `review_mode: quick`, so the residual work is
skill drift against that spec, not a change to this contract.

No implementation code yet. Base spec left immutable.
