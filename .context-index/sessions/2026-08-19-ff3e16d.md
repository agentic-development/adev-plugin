## Intent

feat(reviewer-domain-fit): ship the web-service domain extension

Adds extensions/web-service, a vendored domain extension (extends: software)
that re-enables OWASP-scoped security review for web-service-shaped
projects. domain/ deliberately contains only reviewers.yaml — the five
active default-panel reviewers (referent-integrity, wiring-reviewer,
consistency-analyzer, boundary-reviewer, termination-reviewer), field-equal
to templates/domains/software/reviewers.yaml, plus security-reviewer
re-enabled since OWASP-scoped review fits this artifact class. Everything
else is inherited from `extends: software` via loadDomainConfig's fallback.

Adds a fourth catalog entry (templates/extensions-catalog.json) and updates
tests/cli/init-extension-picker.test.mjs's positional answers for the
resulting 3-entry-plus-skip prompt shape.

Verified against the now-fixed resolveDomain() (prior commit): a scratch
project with top-level `domain: web-service` installed resolves 6 reviewer
entries via `adev governance materialize --registry review`, not the
software fallback.
