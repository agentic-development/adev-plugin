## Intent

feat(agent-reliable-state-artifacts): plan-task events + lifecycle skill instruction adoption

Implements two sibling specs in the agent-reliable-state-artifacts charter:

- plan-task-events: /adev:plan emits one plan_task pending event per task
  instead of per-task issues; /adev:implement reads task state from
  currentState(spec).planTasks and emits transitions; architectural
  detector enforces plan-file immutability after authoring.
- lifecycle-skill-instruction-updates: every lifecycle SKILL.md rewritten
  to call requireGate / reportStep / reportReviewer / reportValidator /
  reportPlanTask / getIssueManager helpers instead of parsing markdown
  tables or grepping .review.md frontmatter. lib/manifest.mjs lifted from
  three private copies into a public shared loader. All 14 in-scope skill
  files gain an API reference appendix.
