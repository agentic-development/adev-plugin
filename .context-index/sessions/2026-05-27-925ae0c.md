## Intent

fix(implement): remove context: fork to restore subagent dispatch capability

context: fork sandboxes the skill's execution context, making the Agent
tool unavailable. /adev:implement must dispatch fresh subagents per task
(implementer, spec reviewer, code-quality reviewers, final reviewer) and
therefore cannot run in a forked context. Orchestrators do not fork —
isolation comes from the subagents they dispatch.

Applies to all three provider variants (primary, codex, opencode).
Adds a regression test asserting context: fork is absent from implement's
frontmatter, with an explanatory message so the invariant doesn't rot.
