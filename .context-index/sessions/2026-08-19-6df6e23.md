## Intent

test(evals): tier 1 + tier 2 behavioural regression checks for disclosure

Of 531 test files, 156 assert on SKILL.md prose and 11 dispatch an agent. So the
safety net for moving ~500 KB of prose across 30 skills was almost entirely
"does this string still appear somewhere" — true, and blind to the regression
progressive disclosure actually risks: the agent reads the one-line summary in
the body, never opens the companion it points at, and silently skips the step.
Every prose assertion stays green.

TIER 1 — read trace (lib/eval/read-trace.mjs + read-trace.eval.mjs)

The trace is OBSERVED, not self-reported. hooks.json registers session-capture.sh
on PostToolUse with matcher `.*`, and I verified empirically that it records tool
calls made by dispatched SUBAGENTS, with absolute paths. Asking an agent what it
read would be weaker — a cooperative model reports what it was asked about.

Two phases, because a node test cannot dispatch a model: snapshot the log, run
the scenario in-session, write traces/<scenario>.json; the eval then compares
that against baselines/<scenario>.json. Missing companions fail. EXTRA reads do
not — an agent reading more than the minimum is doing its job, and failing on it
would make the baseline a straitjacket.

First real capture found a bug in my own harness before it found anything about
the skill: the scenario used a relative path, the subagent resolved it against
its own cwd, and it read MAIN's pre-refactor monolithic SKILL.md — which still
has all 23 passes inline, so it could describe Pass 12 without opening any
companion. A less careful harness would have recorded that as a passing baseline.
Scenarios now use absolute paths. The corrected run reads the body and exactly
one of 23 audit passes, which is the disclosure contract working.

TIER 2 — artifact shape (artifact-shape.eval.mjs)

Static, free. Asserts each artifact-contract section is reachable by following
pointers from the body, and that none is stranded in a file no pointer chain
reaches — which prose tests cannot see, since they read the whole tree while an
agent reads only where the body sends it.

Its first version anchored on section HEADINGS and could not fail: a heading is
exactly what disclosure leaves behind as a stub, so the string was always
reachable. Caught by probing, not by review. Anchors are now content that lives
only in the companion carrying the substance.

FALSIFIED, all of it, per adev-plugin-no-falsification-step-973s:
  tier 1 — companion never opened / whole catalogue pulled / trace not of this
           skill / baseline with no trace  -> each fails
  tier 2 — pointer removed so a section is stranded -> fails

Tier 3 (LLM-as-judge) deliberately omitted. Expensive, noisy, and treating it as
the entry point is why this kind of testing usually never ships.

Excluded from `npm test` by the existing tests/evals/ rule; run on demand.
Suite unchanged at 7207.
