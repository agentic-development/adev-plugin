## Intent

docs(adrs): ADR-0012 plan-adjacent sidecar artifacts (Proposed)

Establishes the sibling-file convention (<stem>.<purpose>.md) for skills
that produce auxiliary data tied to a Live Spec or plan but must not
mutate it. Resolves the architectural tension between CON-8 in
plan-task-events.spec.md (artifact markdown is read-only after authoring)
and the legitimate need for skills like /adev:route and /adev:review-specs
to record per-task or per-finding metadata alongside the primary artifact.

Status: Proposed. Flips to Accepted when (1) /adev:route fix lands per
issue-526, (2) CON-8 amendment lands in plan-task-events.spec.md, and
(3) lib/plan-immutability.mjs gains the mutate-then-single-add detector.

Permitted peers enumerated (closed enum, ADR-managed):
  - <spec-stem>.review.md (existing — /adev:review-specs)
  - <spec-stem>.validate.md (existing — /adev:validate)
  - <spec-stem>.blockers.md (new in commit 7e333fd — /adev:build BLOCK path)
  - <plan-stem>.routing.md (target for issue-526)

Four alternatives considered and rejected: lifecycle-log-only,
targeted mutation, per-task subdirectories, single combined sidecar.

This ADR is the foundation for both issue-526 (/adev:route plan mutation,
sidecar fix + 5-plan migration) and issue-527 (HIGH priority — restore
auto-retry on review BLOCK via state machine + /adev:specify revision
workflow). Issue-527 is not blocked on this ADR but is informed by it.
