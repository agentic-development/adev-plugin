## Intent

feat(spec-lifecycle): dispatch one authoring subagent per implicated section anchor

Adds the CLI wiring the SKILL.md prose needs to actually drive Task 6's
authoredSections parameter end-to-end:

- groupBlockersByAnchor now filters to defect-classed blockers only
  (decision/external are never authored -- Task 9's DECISION_REQUIRED/
  EXTERNAL_REMEDY paths own their resolution instead). Entries without a
  finding_class field default to defect (backward compat).
- parseBlockersSidecar extended to also parse finding_class from the
  sidecar's per-entry YAML block.
- New `adev specify group-blockers --spec <path>` CLI verb: resolves
  heading anchors, groups defect-classed blockers, and returns each
  anchor's current section text -- so the skill can dispatch one
  authoring subagent per anchor without importing a lib function into
  skill prose (cli-driver-surface charter).
- `adev specify revise` gains `--authored-sections <json|@path>`,
  parsed into the Map reviseSpec already expects.
- skills/specify/SKILL.md's Revise Mode gains a per-anchor authoring
  dispatch step; full mechanics extracted to a conditional-loading
  companion file (skills/specify/revise-mode-authoring-dispatch.md)
  to stay under the Copilot SKILL.md size cap.
