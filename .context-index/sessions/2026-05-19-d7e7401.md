## Intent

fix(docs): move /adev:document output under docs/modules/ to honor superseded-files convention

The `/adev:document` skill spec mandates writing `docs/architecture.md`
and `docs/GENERATED.md` at the docs top level. This project's
tests/docs/support-polish.test.mjs explicitly forbids architecture.md
(removed in commit 0623ca2 "remove superseded docs files") and
requires a README.md breadcrumb in every top-level docs file.

Failing CI checks:
  - "Superseded docs removal" — docs/architecture.md should not exist
  - "Breadcrumb and next/previous navigation" — docs/architecture.md
    and docs/GENERATED.md missing README.md breadcrumb

Resolution for this PR:
  - Delete docs/architecture.md. The module-map and dependency-flow
    content is captured per-module under docs/modules/<slug>.md.
  - Move docs/GENERATED.md → docs/modules/GENERATED.md so it shares
    the same subdirectory as the rest of the generated output.
  - Update GENERATED.md preamble to document the divergence from the
    skill spec for future readers.

Follow-up (out of scope for this PR): the `/adev:document` skill itself
should be updated to write under a configurable subdir (or default to
docs/modules/) so it doesn't collide with project docs conventions on
adoption. Tracked separately.
