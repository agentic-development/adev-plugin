## Intent

feat(session-awareness): add fromTranscript to lib/session-summary.mjs

Read a Claude Code transcript JSONL line-by-line and render the
session-summary markdown body. Applies `redactSecrets` unconditionally
per the SEC-1/SEC-9 invariant. Returns:
  - kind: 'session-end' on success (body + optional metadata)
  - kind: 'placeholder' on missing file, empty file, or unparseable JSONL

Optional usage-derived metadata with SEC-12/SEC-13 producer-side
validation: inputTokens, outputTokens, costUsd, model. Validation
failures OMIT the field rather than persisting a sentinel.

Tolerates per-line JSON parse failures (skips silently) so a single bad
line does not poison the whole transcript. Never throws.

6 tests cover happy path, missing file, malformed JSONL, redaction
integration, valid-usage extraction, and invalid-usage omission.
