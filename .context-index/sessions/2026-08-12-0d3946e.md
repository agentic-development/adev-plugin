## Intent

docs(context): harness simplification study + measurement-integrity spec

Adds the research artifact behind the current Phase 0 work and the
cross-cutting spec it produced, together with the architecture review
that blocked that spec.

The study (.context-index/research/harness-simplification-study.md) asks
whether the adev lifecycle can be simplified without losing quality. Its
finding: the repo has ~80 prose-shape guards that detect whether skill
text changed, but nothing that detects whether output quality dropped —
so a simplification sweep would fail CI on rewordings while real
regressions passed silently. It proposes fixing measurement first, then
building a regression harness, then simplifying.

measurement-integrity.spec.md covers that first phase. It is committed
at status: review-blocked with its .review.md and .blockers.md sidecars,
because the architecture review returned BLOCK on four findings:

  - ADR-0012 closes the set of permitted sidecar filenames, so the
    proposed rotated report names need an ADR amendment first
  - the Spec:-trailer escaping contract (the code half of this is fixed
    separately in fix/post-commit-trailer-injection)
  - the check-ID enum is unresolvable as written: governance/validate.yaml
    uses qualified IDs while the CLI documents unqualified ones
  - behavior 4's premise was factually wrong (see below)

That last finding also corrected the study, and the retraction is
recorded in the artifact rather than quietly edited out:
adev/frontmatter-present was listed as pure overhead on the basis of its
52% share of lifecycle events. It is in fact an error-severity diagnostic
that fires only on missing or malformed frontmatter — the volume is ~400
real violations, caused by the spec templates themselves placing an H1
above the frontmatter delimiter. Tracked under epic-104.

The spec is deliberately not merged as ready. It needs either a narrowing
(dropping behavior 4, splitting report rotation into its own ADR-gated
spec) or an ADR amendment before it can pass review.
