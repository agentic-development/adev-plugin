## Intent

fix(test-strategies): revision 3 — close the round-2 blockers

Round-2 quick-tier re-review confirmed 5 of 7 round-1 blockers closed
against shipped code and found 4 more. This revision closes them.

SA-13 (all three profiles): each spec independently claimed to be "last"
in the detection cascade. Only one can be, so order among the three was
undefined and the "every earlier rule wins by construction" claim was
false once all three land. Real collisions: tolerances/x.baseline.json
and reconciliation/__snapshots__/x.snap. A canonical order —
reconciliation, then tolerance, then snapshot — is now set once in the
snapshot spec's charter extension note and referenced by the other two.
Directory-anchored rules resolve before extension-anchored ones.

SEC-6 (ledger): revision 2's fix specified a mechanism that does not
exist. Author-type/Operator are git commit-message trailers written by
.githooks/prepare-commit-msg, not a runtime channel a CLI verb can read;
the derivation fails OPEN (hasSessionId ? agent : human, plus an
empty-string fallback) and its only input is a session-tracking file the
attesting session itself writes. Building an auth guarantee on that is
worse than none because it reads as verified. Withdrawn. operator_deferred
is now reachable only via a task named in a checked-in deferral policy
file — a human-authored diff a reviewer can see — so there is no runtime
path to it at all.

SA-12 (ledger): event-schemas.mjs expresses only a flat per-discriminator
required-field array and cannot say "required when strategy_id is
snapshot". Both baseline fields become unconditionally optional there and
the pairing check moves to the emitter, leaving a validated contract
intact. The spec now also states what baseline_captured_at can and
cannot prove instead of implying tamper-proofing.

CON-9 (ledger): the retroactivity cutoff was defined twice in one
paragraph, incompatibly. The data-anchor reading would have let the
recorder set its own exemption boundary and made a project that never
records permanently exempt — reproducing 235-of-391 exactly. Version
anchor only; zero recorded outcomes now means maximally unverified.

Also: SEC-7 states system-name granularity as the floor for
unmet_requirement (missing_env_vars/missing_tools are nullable, so a
probe-only failure has no finer name), and CON-10 removes the
docs/concepts.md row from the shared 9 -> 12 table — that file contains
no strategy count.

npm test: 5474 pass, 0 fail, 2 todo — unchanged from baseline.
