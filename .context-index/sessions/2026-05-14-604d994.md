## Intent

feat(cli-driver-surface): land driver-substrate (verb registry + adev gate)

Implements driver-substrate.spec.md, the foundation of the
compiler-driver pattern. Adds the Map-keyed verb dispatch table in
cli/index.mjs, the lib/cli/<verb>.mjs uniform contract (run + help +
optional LIFECYCLE_STEP), the first exemplar helper (lib/cli/gate.mjs
for adev gate require), and the AST-style pattern test that enforces
the contract across all current and future helpers.

  Driver substrate (cli/index.mjs + lib/cli/)
    - VERB_REGISTRY Map keyed by verb name; each entry is either a
      legacy adapter closure (run.length === 0, reads process.argv
      internally) or a dynamic import of lib/cli/<verb>.mjs.
    - Dispatcher: argv → verb → factory → module → run({ projectRoot,
      argv, manifest }). 28-line contract comment block above the
      registry documents the convention.
    - Exit codes per Constitution Principle 4 / hook protocol:
        0  success
        1  fatal (unknown verb, missing run export, generic exception)
        2  gate-blocked (err.code === 'GATE_BLOCKED' — robust across
           module-instance boundaries, safer than instanceof)
    - stripAnsi() for stderr-bound verb names + error messages
      (SEC-2 from driver-substrate.review.md). Scoped to dispatcher
      stderr only; intentional ANSI on stdout (e.g., future adev
      diagnose severity coloring) is unaffected.
    - printVerbRegistry() helper for both no-verb (stdout) and
      unknown-verb (stderr) paths.

  lib/cli/gate.mjs (first exemplar helper)
    - adev gate require --skill <name> --spec <path>
    - SKILL_STEP_MAP translates skill name → lifecycle step entered.
    - Path containment (SEC-1): resolves --spec relative to
      projectRoot and rejects anything that escapes the tree.
    - Deliberately does NOT export LIFECYCLE_STEP — gate is a query
      primitive, not a lifecycle step. Pattern test's requireGate-
      first AST assertion correctly skips it.

  Tests (3 new files + 3 fixtures)
    - tests/cli/dispatcher.test.mjs: 5 tests covering behaviors 1, 7,
      8, 9 + smoke checks for registered verbs. 2 documented todo
      placeholders for GateError exit-2 / non-GateError exit-1
      from a registered helper (deferred — gate.test.mjs covers
      these end-to-end with the real helper).
    - tests/cli/gate.test.mjs: 10 tests covering all error cases
      and gate behaviors for `adev gate require` (missing --skill,
      missing --spec, spec not found, path traversal containment,
      passing gate, blocked gate (exit 2), exports check, no
      LIFECYCLE_STEP export, unknown skill, --help).
    - tests/cli-driver-pattern.test.mjs: walks lib/cli/*.mjs and
      asserts (1) every module exports run + help, and (2) any
      module exporting LIFECYCLE_STEP has requireGate(...) as the
      first executable statement of run(). Detector uses regex /
      source-text analysis — no JS parser dependency per
      Constitution Principle 1 (zero new deps).
    - tests/fixtures/cli/{conforming, non-conforming-no-run,
      non-conforming-no-gate}.mjs: fixture-driven tests that verify
      the detector itself catches missing run exports and missing
      requireGate-first calls.

  Lifecycle artifacts

    - cli-driver-surface/charter.md Capability Map: 4 capabilities
