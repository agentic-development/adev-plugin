## Intent

feat(agent-reliable-state-artifacts): one-shot migration tool

Adds lib/migrate-state-artifacts.mjs + the `adev migrate` CLI wiring
already shipped with the rendering-layer commit. Converts a project's
four legacy state artifacts to charter-era shapes in one semantically-
idempotent invocation:

- tasks.md         → tasks.json
- build-state/*.json → lifecycle-state/*.jsonl (+ directory rename)
- .execution-state.md → .execution-state.json
- milestones.yaml    → milestones.json

Plus the constitution Context Routing row update, scoped to the active
table (CONSTITUTION_AMBIGUOUS_MATCH on multiple occurrences, code-fence
safety honored). Idempotency mechanism is skip-on-completion (per-artifact
checks short-circuit when target exists, exit 0). Path containment runs
realpath-prefix on every read AND write path before any parser executes;
per-artifact size caps and slug allowlist enforce bounds. Collisions are
fatal — RENAME_COLLISION on pre-existing lifecycle-state/, and
LIFECYCLE_STATE_FILE_EXISTS on pre-existing per-file targets (never
appends/merges). Parse-error advisories redact raw legacy content to a
200-char control-stripped window. /adev:sync advisory emitted only on
constitution action: "migrated".

37 migration-tool tests passing across 7 files (parity, idempotency,
collision, containment, redaction, constitution, CLI).
