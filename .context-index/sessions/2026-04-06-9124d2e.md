## Intent

docs: add research artifact on shared session memory

Compare adev-plugin's existing persistence (sessions, specs, plans,
issues, active-plan pointer) against industry approaches (Claude Code
native, Cursor, Replit Agent, Letta/MemGPT, mem0, LangChain).

Key finding: filesystem-based memory is competitive with specialized
frameworks (Letta benchmark: 74% vs 68.5%). The gap is in when state
is captured (post-commit vs per-turn) and what is captured (artifacts
only vs artifacts + learnings + execution state).

Recommends: execution state file, session-start resume injection,
learnings file, and context freshness hashes as Tier 1 improvements.
