feat(cli-driver-surface): PR 7 — extract context/state primitives bundle

Adds 5 new CLI verb modules covering the long-tail context-loading and
lifecycle-state-projection inline-Node blocks across 6 skills. Multi-mode
verb pattern per spec Behavior 9 (canonical CLI-verb naming, shared).

  adev context load --spec <p> [--plan <q>]
    → wraps loadSpecContext + getPlanProgress (lib/meta-tools.mjs)
    Replaces heredocs in skills/implement (Step 1), skills/plan
    (Essential Context), skills/validate (Check 12e plan-progress).

  adev verify spec  --spec <p> [--plan <q>]
  adev verify issue --issue-json <json> [--note <action> ...]
    → wraps verifySpecImplemented + verifyIssueCompleted +
      formatConfidenceNote (lib/reality-check.mjs)
    Replaces heredocs in skills/hygiene (Step 8 reality drift check)
    and skills/validate (After-Validation Step 3 issue confidence note).

  adev state list   [--status <s>] [--module <m>]
  adev state current --spec <p>
  adev state events  --spec <p> [--event <type>]
    → wraps findSpecsByStatus (lib/meta-tools.mjs) + currentState /
      filterEvents / listLifecycleStates (lib/lifecycle-state.mjs)
    Replaces the findSpecsByStatus loop in skills/status (Mode --all).
    current/events introduced as canonical verbs for future PRs.

  adev execution-state read | write [flags] | clear
    → wraps readExecutionState / writeExecutionState /
      clearExecutionState (lib/execution-state.mjs)
    Replaces the three prose-form `node -e` references in skills/implement
    at Steps 2c-pre (write active), 2d-blocker (write blocked), and 4
    (clear on completion).

  adev build-state read | create | record | next  --spec <p> [flags]
    → wraps readBuildState / createBuildState / recordStepResult /
      getNextStep (lib/build-state.mjs)
    Replaces the three heredocs in skills/build/SKILL.md (Dispatch Loop
    steps 1, 2, 4).

All five helpers follow the driver-substrate contract:
  - Export run({projectRoot, argv, manifest}) and help().
  - Do NOT export LIFECYCLE_STEP — context/verify/state queries are
    observational metadata, not lifecycle-step entry/exit. The cli-driver
    pattern test correctly does NOT assert requireGate-first on these.
  - Path containment via the SEC-1 mirror (resolveContained) shared with
    gate.mjs, source-manifest.mjs, domain.mjs.
  - Silent stdout on success (single-line JSON) or empty for `clear`.
