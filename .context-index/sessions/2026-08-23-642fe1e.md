## Intent

chore(issues): land the CLI-driver-surface issues retrofit from release/next onto main

PR #313 ("refactor(issues): retrofit /adev:issues onto the CLI driver
surface") was merged with release/next as its base branch instead of main,
so main never got adev issues create/epic/update/close/dep/list/ready/
milestone and the SKILL.md conversion off inline lib-directives. This merges
that work onto main, reconciling it with main's own independent additions
(beads-board-git-topology, claim/release/stale/set-modules/next for the
autonomous bugfix loop) that release/next never received.

The `board` verb name collided between the two lines (release/next: print
the board; main: migrate its git topology) — lib/cli/issues-board.mjs now
dispatches on argv[0] === "migrate" to tell them apart, since a subcommand
can never collide with a --flag.
