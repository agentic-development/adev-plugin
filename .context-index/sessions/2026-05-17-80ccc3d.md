## Intent

chore(agent-reliable-state-artifacts): gitignore CAS lock+tmp; add review.md

Two follow-up fixes after the build pipeline:

1. Add .context-index/tasks/tasks.json.lock and .json.*.tmp to
   .gitignore. The CAS layer creates these at write time and normally
   cleans up in the finally block, but SIGKILL / OS crash / rename
   failure can leave them behind. Committing the lock file would
   break writes on every clone (every CAS attempt → EEXIST → retry
   3x → STALE_BOARD_WRITE). The real tasks.json itself stays tracked.

2. Add concurrent-write-protection.review.md — the rev-2 review
   artifact was written to disk during the build but never staged
   to git. The other lifecycle artifacts (spec, plan, validate) were
   committed in the earlier commits on this branch.
