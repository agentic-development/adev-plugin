fix(hygiene): add context_pack divergence audit to registry-drift (pass 19)

bundled/domain starter, so an id present on both sides with a stale

reviewer sees, with no error or failed run to flag it. Adds a fourth
audit, hygiene/context-pack-divergence (WARNING), scoped to
bundled/domain-sourced entries; a project's own entry is deliberate
customization, not drift to flag.
