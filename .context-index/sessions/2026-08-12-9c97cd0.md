## Intent

feat: add pr-review-brief feature charter

Charters the reviewer-facing content contract for pull requests: what a PR
must tell a human, and the enforced boundary between what the author claims
and what the lifecycle measured.

Grounded in .context-index/research/pr-review-experience.md (included here),
which measured the last 40 merged PRs: excluding release-please (n=32), the
median is 116 added lines but p75 is 2,100 — only 5 of 32 land in the
100-900 band, and the 41% over 400 additions carry 96% of all changed lines.
The lifecycle already computes what a reviewer needs to triage those diffs
(Spec:/Plan-task:/Author-type: trailers, /adev:route blast-radius scores,
/adev:validate verdicts) and discards all of it at PR time.

Scope was narrowed after a cross-charter conflict check found three existing
charters already own most of the adjacent territory:

- cli-driver-surface owns the `adev <verb>` dispatch substrate, so this
  module contributes a verb rather than defining how verbs are wired.
- cicd owns .github/workflows/, so delivery is out of scope. It is
  deliberately NOT listed as a dependency — the direction is inbound, and
  the generator must stay buildable and testable with no CI in place.
- copilot-provider owns .github/skills/ and the AGENTS.md sync target.

Two guardrails are written into Quality Attributes from findings during
chartering:

- Security cites issue-582: trailer values are consumed as data, never
  interpolated into a shell or `node -e` context, and quoted on output so a
  crafted Spec: value cannot corrupt markdown or frontmatter parsing.
- Observability requires loud degradation. Paired with Invariant 3 (a task
  with no routing entry renders UNKNOWN, never low-risk), this designs out
  the failure mode where an empty attention map reads as "nothing risky
  here" — relevant because ~20 legacy plans still lack routing sidecars
  (issue-528).

Also records that the copilot-provider charter's premise "AGENTS.md is
already written by sync" does not hold: manifest.yaml declares only
CLAUDE.md as a sync target and AGENTS.md is absent, so a write path is
required. Flagged for that charter to correct.

Tracked as epic-106 (issues 529, 595-599, 602).
