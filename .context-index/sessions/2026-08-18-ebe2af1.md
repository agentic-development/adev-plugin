docs(reviewer-domain-fit): revise falsification-gate to rev 5 — remove a verification that verifies nothing

theatre.

adev --version does not exist. The dispatcher reads argv[2] as a verb name
(cli/index.mjs:1937) and has no --version entry, so both the installed adev and a
worktree-local node cli/index.mjs print 'unknown verb: --version' plus the usage
banner and exit 0. Verified empirically: BYTE-IDENTICAL output. That banner is a
constant emitted by the same code in every checkout, so AC-5's 'all runs share one
value' would have passed trivially in exactly the scenario the pin existed to
catch.

This is the third time in this spec's history that a check I added could not
detect the condition it named — the same shape the spec itself blocks on in Step 3
('an empty errors array does not prove a pack resolved'), reintroduced in the
sub-step written to close it.

The resolved plugin root IS a sound discriminator: getPluginRoot() derives from
lib/profiles/index.mjs's own location two levels up, so it distinguishes a
worktree-local library from the installed one. Rev 5 records that alone, and
states explicitly why --version must not be used, so the next author does not
reintroduce it.

CON-1: Postcondition 3 and two acceptance criteria said 'the five runs', which
contradicts PC2's UNMAPPED ids and PC4's reduced denominator. Rephrased to
'one run per MAPPED id' and 'each scorable run'.

rev 4 -> 5, sidecar cleared. Acceptance criteria unchanged at 21.
