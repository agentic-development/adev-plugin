## Intent

feat(setup): add adev init ensure-gitignore [--remove] sub-verb

New CLI sub-verb wraps ensureManagedBlock/removeManagedBlock from
lib/gitignore-installer.mjs. Mirrors init-prompt-session-capture's
run({ projectRoot, argv, manifest }) adapter shape.

Behavior:
- default (no --remove): respects setup.managed_gitignore knob; prints
  the "disabled by manifest" advisory when false.
- --remove: ALWAYS bypasses the knob (operator escape hatch — must be
  able to remove a previously-installed block even after disabling
  install-time writes).

Exit codes: 0 success, 1 EACCES, 2 UNSAFE_GITIGNORE_PATH.
