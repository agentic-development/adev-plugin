## Intent

feat(unified-gates): adev gate doctor — verify gates run and tests get collected

Five diagnostic families over governance/gates.yaml: sh-globstar
under-expansion, runner collection diff, gate binary resolution,
unsubstituted {{ }} placeholders, and gitignored/missing referenced
paths, plus CI-invocation checks per gate.

Static by default. This repo's own test gate is 'npm test' and the
doctor is reachable from /adev:validate and /adev:hygiene, both
reachable from a test run, so executing by default would be reentrant.
--execute is opt-in behind an ADEV_GATE_DOCTOR environment guard that
terminates the cycle at depth one by construction.

Follows npm-script indirection: the adev-plugin finding was not in the
gate command ('npm test') but one hop away in package.json scripts.test.
A doctor reading only the literal gate command would have missed the bug
that motivated it.

Wired into /adev:validate as check-14 (deterministic, warning severity).
