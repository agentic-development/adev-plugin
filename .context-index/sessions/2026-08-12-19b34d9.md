## Intent

feat(pr-review-brief): spec pr-body-advisories; composition rev 2

Covers the charter's two should-haves — size advisory with exception
classes and reading order for multi-commit PRs — and closes the Capability
Map: all six capabilities are now specified.

Both are sections of the brief pr-body-composition already produces, not a
second artifact. Its revision 1 fixed the marker's contents at three
sections, so the two specs would have contradicted each other on the one
thing both depend on. Composition goes to revision 2 carrying a five-slot
section list with an owning-spec column:

  1 size advisory (advisories) | 2 attention map (composition)
  3 reading order (advisories) | 4 traceability | 5 verification

Edited in place rather than via --amend: the spec is still review-pending
and has never been reviewed, and the specify skill reserves amendment
artifacts for shipped specs. No `spec_revised` event — `adev report` has no
event type for it and `adev specify revise` requires review-blocked status
plus review/blockers sidecars that do not exist. Git history is the record.

Size advisory leads the brief because it is the only section that changes
what a reviewer does before opening the diff. Threshold defaults to 400
additions, which is where the charter's own measurement of this repo breaks
(the 41% of PRs over 400 additions carry 96% of all changed lines), and is
overridable via a new optional manifest `pr:` block alongside mirror_globs.
Size is reported raw and net of mirror globs, both shown, so the exclusion
of providers/*/skills/** is visible rather than silent.

The verb asserts no exception class. Only "generated mirror" has
deterministic evidence and that is already in the net figure; guessing
"mechanical sweep" from diff shape would launder a heuristic into an
excuse. The advisory names the three classes and points at the review
packet's ## What section for the author to claim one.

Reading order's input is ## Parallelization, free prose emitted by
skills/plan/SKILL.md:458 with no schema behind it, so a credulous parser is
the real risk — a confidently wrong reading order is worse than none. Fixed
narrow grammar (- Group <A-Z> (<opaque qualifier>): ... with ordered
Task <N> extraction), verified against the shapes actually on disk. The
qualifier is never interpreted: "depends on Tasks 3-6" stays a string.

Five-rung fallback ladder, each rung named in the rendered output, because
an order derived from commit chronology looks identical to a planned one
unless the brief says which it is. All-or-nothing per plan: one malformed
group line drops that plan whole, since a mix of parsed and unparsed groups
renders as complete while silently omitting tasks.

Bound to issue-616. Sibling of issue-612 (composition) and issue-613
(review packet). Covers issues 601 and 602 from epic-106.
