## Intent

feat(hooks): self-skip post-commit on sessions-only commits

Adds an early-exit guard to `.githooks/post-commit` that skips the capture
write when every changed file in the commit is inside `.context-index/sessions/`.
Breaks the recursive "1 commit -> 1 capture file -> 1 commit" amplification
that occurs when agents commit in-session. Strict prefix match via bash `case`
glob so `.context-index/sessions-archive/` and `.context-index/sessions.bak`
remain captured. Hook still fails-open: any non-session file in the commit
or any empty `$CHANGED_FILES` falls through to the existing capture path.
