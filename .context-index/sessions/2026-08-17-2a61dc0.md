## Intent

docs(review): document per-pack delivery and path-manifest sections

Adds `delivery: inline | manifest` to the documented context-pack schema —
default, extends precedence, and INVALID_PACK_DELIVERY as a load error — plus
the role="path-manifest" section shape (one section per include in declaration
order, title fallback chain, byte-sorted repo-relative paths, <no matches> for
an empty include).

Amends the size-bounding prose for manifest delivery: the target spec is exempt
from both caps and never truncated (TARGET_SPEC_OVERSIZE warning instead), no
truncation-notice section is emitted, and the spec arrives as the dispatch
assembler's own role="target-spec" section.

Records that the bundled flip has NOT landed: defaults.yaml declares no
delivery key, so every bundled pack still resolves to inline and reviewers do
not yet receive path manifests. The designed end state is marked as gated on
the open tracker adev-plugin-j7pq.7, whose two security gaps are named in a new
Known limitations subsection.
